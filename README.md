# 阿特拉斯 / Atlas

**让酒馆里的故事，有一张可以探索的地图。**

Atlas 是一个 SillyTavern 世界引擎扩展。它从世界书与聊天剧情中整理地点、人物和物品，在每轮回复后推演世界变化，让你在同一个工作台里查看地图、世界时间、人物动态和事件记录。

世界引擎运行在浏览器中，常规安装无需额外部署 Atlas 服务端。自动推演和地图生成需要先配置模型 API，并会产生相应的模型调用。

当前版本：[v0.9.100](https://github.com/kjngstar/atlas-sillytavern-plugin/releases/tag/v0.9.100)。修复父子地图导航、邻近地点布局和稀疏地图取景，并移除缺少依据的内容数量与长度上限。更新与验证范围见 [0.9.100 更新说明](docs/atlas-0.9.100-更新说明.md)。

## 能做什么

| 功能 | 使用体验 |
| --- | --- |
| 多层地图 | 从世界、城市逐层进入建筑和房间，查看已生成的道路、水系、区域与室内陈设；各张地图保留自己的平移和缩放。 |
| 人物与物品 | 点击地图标记查看详情，也可从人物、物品列表查找世界中已记录的对象。 |
| 世界推演 | 根据本轮剧情更新世界时间、地点、人物状态与事件，在推演回执和时间线中查看变化。 |
| 场景上下文 | 在正文生成前提供主角当前可接触的场景与线索，按可知范围过滤后台信息。 |
| 回合与存档 | 按聊天隔离世界数据；编辑、删除或切换已提交回复时，回退相关世界变化，再按新结果推演。 |
| 外观与预设 | 切换显示范围和皮肤，编辑分段提示词，为推演任务配置连接与分批方式。 |

地图布局根据已登记的地点和来源资料生成。资料不足或模型输出不合要求时，部分地图可能暂缺布局，可查看回执并补充资料或重试。

## 安装

需要 **SillyTavern 1.12.0 或更新版本**。

1. 打开 SillyTavern 的扩展管理，点击「Install extension / 安装扩展」。
2. 粘贴以下仓库地址并安装：

   ```text
   https://github.com/kjngstar/atlas-sillytavern-plugin
   ```

3. 刷新酒馆页面，在扩展菜单中打开「阿特拉斯 / Atlas」。

链接安装使用仓库默认分支。希望保留可回溯的固定版本时，可使用上方版本 tag 的完整仓库文件。

手动安装可将完整仓库目录放入 SillyTavern 的 `public/scripts/extensions/third-party/atlas-sillytavern-plugin/`。请保留脚本、样式、`ui/`、`dist/` 和 `manifest.json`，并确保只启用一份 Atlas。

仓库已包含运行所需的构建产物；普通使用者无需安装 npm 依赖或 Python。

## 快速上手

1. **先打开一个聊天。** Atlas 的世界数据与当前聊天关联，不同聊天分别保存。
2. **打开世界工作台。** 在「预设与外观 → API 连接」配置连接、密钥与模型，并在「任务与分批」中核对任务使用的连接。
3. **建立当前世界。** 点击「建立当前世界」，从当前可用的世界书和剧情资料开始整理世界；已有存档可通过世界后台导入或恢复。
4. **回到聊天继续故事。** 正文回复完成后，Atlas 推演这一轮的世界变化。在「世界推演」查看回执，在「世界时间线」回顾事件。
5. **打开地图探索。** 使用左侧地图树或顶部面包屑切换层级，点击地点、人物或物品查看详情。遇到失败时，在「诊断」查看具体原因。

连接、提示词和外观都可以稍后调整。没有可用的推演连接时，仍可浏览已保存的地图与世界数据；新增推演和 AI 地图生成需要可用的模型连接。

## 界面与皮肤

工作台顶部提供「完整界面」「地图专注」「纯地图」三种显示范围。它们共用当前世界和地图，可以按阅读或探索需要随时切换。

地图上的「地图工具」默认收起。展开后可使用视图选择、缩放、网格、小地图、图例和地图导出；收起后仍可拖动地图、使用滚轮缩放，或按 `F` 适应视野。

### 换一套外观

打开「预设与外观 → 外观」，选择已安装皮肤，或点击「导入皮肤」导入 JSON / ZIP 文件。图片皮肤直接选择 ZIP，**无需解压**。

| 皮肤 | 风格 | 获取方式 |
| --- | --- | --- |
| 星幕 | 深色星图与原有地图笔触 | 内置 |
| 纸面 | 浅色纸面与墨色线条 | 内置 |
| 晴空信笺 | 晴蓝天空、奶白信纸与云朵装饰 | [下载皮肤 ZIP](skins/qingkong-xinjian/Atlas-QingkongXinjian-1.0.1.zip?raw=true) |
| 山河志 · 青绿宣纸 | 宣纸、青绿山水与印章标记 | [下载皮肤 ZIP](skins/shanhezhi/Atlas-ShanheZhi-1.1.1.zip?raw=true) |

可分别调整框体、面板、按钮、字体、颜色和地图笔触。外观切换保留地图位置与缩放，不触发世界推演。

图片皮肤保存在**当前浏览器、当前酒馆地址**下。换浏览器、换地址或清理浏览器数据前，请导出完整皮肤包以便恢复。想制作自己的皮肤，可以阅读[皮肤制作说明](docs/atlas-skin-authoring.md)。

## 存档、导出与更新

世界数据随当前酒馆聊天保存。重要存档建议同时保留聊天备份和 Atlas 会话备份；旧世界资料可作为迁移输入，升级前请先备份。

| 导出内容 | 用途 |
| --- | --- |
| Atlas 会话备份 | 用于世界会话备份与恢复，可在世界后台操作。 |
| 当前地图 JSON | 用于分析当前图及子图的地点关系、布局与几何；选择世界图可导出当前视角下的世界图层。此文件不能作为世界存档导入。 |
| 完整皮肤包 | 搬迁或备份当前外观及图片资源。 |

在扩展管理中更新 Atlas 后，刷新酒馆页面即可加载新版本。手动覆盖时请替换完整安装单元，避免混用不同版本的文件。需要回溯版本时，从仓库的 [Tags](https://github.com/kjngstar/atlas-sillytavern-plugin/tags) 选择已标记版本。

卸载前请先备份需要保留的聊天、世界会话和皮肤。随后在扩展管理中停用并删除 Atlas。

## 常见问题

**安装后为什么没有地图？**

请先打开聊天、配置模型连接并建立当前世界。地图需要可用的地点资料与成功的布局结果；若回执提示部分完成或失败，先在「诊断」查看对应问题。

**推演失败会影响正常聊天吗？**

推演失败不会阻断酒馆正文回复。可在回执中查看已完成与未完成部分，并对失败部分重试。模型连接、超时或输出格式问题可在诊断中进一步核对。

**地图上的距离和物体位置都是确定的吗？**

地图既包含已确认的信息，也可能包含用于展示的布局估计。资料中没有明确依据的细部位置或距离，应结合地图提示与剧情判断。

**API 使用和日常操作有什么区别？**

自动推演、手动推演和 AI 地图生成会调用所配置的模型，费用按服务商规则计算。浏览已有地图、切换皮肤和展开地图工具不会触发模型调用。
