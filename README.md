# 阿特拉斯 / Atlas

SillyTavern 世界引擎扩展：把一张**会随剧情推进的世界**带进你的酒馆聊天——地图、世界时间、周边 NPC、事件触发，以及每轮回复后的世界推演。

**纯浏览器形态**：世界引擎整体打进 UI 扩展，安装后零配置、零服务端依赖。推演 API 密钥只存在浏览器侧，经酒馆自带后端代理转发，不落任何服务端。

## 功能

- **世界工作台（悬浮窗）**：按住顶栏可拖动的居中窗口，左栏导航 + 中央页面 + 右栏世界变化简览。
  - **概览**：世界名、分支、当前位置、世界时间。
  - **地图**：地区筛选、物件标记、路线预览（确认后只填入输入框）、缩放；首次推演从世界书与剧情提炼建图，此后补充剧情地点。地点可挂子图，面包屑逐层返回，各地图保存自己的平移和缩放；层级深度由对应入口校验，不统一限定为四层。城市、学校等上层地图用地点和名单承载人物；教室、街道等细化场景允许人物标点，未明确的细部位置按展示布局估计。建筑内区域可点击打开地点详情。
  - **附近**：显示同地点已入表人物；其他地点的已知人物单列为“距离未定”供作者查看。玩家角色不会冒充附近 NPC。
  - **变化**：每轮世界推演回执时间轴 + 失败重试 + 场景上下文预览。
  - **推进**：页面前部直接编辑提示词条目：名称、system / user / assistant 角色、正文、启用开关、复制、排序和删除；支持内置默认副本、Atlas 包与 shujuku JSON 导入、当前草稿导出。最终请求预览核对已保存且启用的预设。用「检查当前世界」核对 SQL 一致性和缺失地图，并备份或恢复 Atlas 会话。
  - **API**：配置和切换推演连接，独立保存密钥与模型参数；连接级系统提示词覆盖会在推进页提示。
  - **替换**：管理可选的思考段清理规则和地图外观。
  - **日志**：按聊天与回合查看安全诊断时间线，筛选、搜索、复制摘要、导出 JSONL；可主动开启最多 7 天的本地脱敏归档。
  - **概览中的世界管理**：启停当前聊天、导入旧世界资料、导出或备份会话；未绑定时建立当前聊天的 SQL 世界。
- **生成前注入**：只提供当前语义场景、主角收到的消息和能够接触的公开线索；后台意图、私下想法、未送达消息、远方人物名单和全世界账本不进入正文上下文。无可用内容时不注入。格式使用有界的 `<atlas_scene_context version="2">` 场景／线索块，不写入可见聊天历史；静默生成不会误触发。
- **回复后推演**：最终回复完成后推演世界变化，原子写入世界账本（时间、地点、NPC 状态、记忆），失败不阻断酒馆聊天、可重试、幂等不重复推进。
- **swipe / 编辑 / 删除与世界同步**：每次推演保存 SQL 楼层变更日志；删除、编辑或重新生成已提交回复时，世界自动回退到该回合之前，新变体作为**同级结果**重新推演（时间不累计），历史保留可追溯。
- **动态上下文不写世界书**：每轮动态状态走当前聊天临时注入，宿主注入失败也不回退写书。同步时清理旧 Atlas 动态条目，保留用户静态设定。推演仍可只读角色卡世界书资料。
- **自动场景判断**：默认推演提示词根据本轮正文和上下文判断主角位置，允许不带逐字引文的唯一地点推断，并显示“剧情推测”来源；意图、远景和远方 NPC 不作为已抵达。手动定位入口位于“作者确认”，用于纠偏。自定义提示词保持原样，需在推进页检查或切换到新默认预设。
- **多聊天隔离**：绑定信息只写入当前聊天的 `chatMetadata`，A / B 聊天互不串线。

## 安装

1. SillyTavern ≥ **1.12.0**。
2. 在 SillyTavern 扩展管理里点「Install extension」，粘贴本仓库链接。
3. 刷新页面，扩展菜单出现「阿特拉斯 / Atlas」。

没有服务端组件、没有配置文件——装完即玩。也可以手动把仓库内容复制到 `data/<用户>/extensions/` 下的扩展目录。

## 快速上手

1. 点扩展按钮打开世界工作台。
2. 在「概览」绑定已有世界，或建立空地理新世界；需要时可导入世界 JSON。
3. 在「API」配置端点、密钥和模型名；在「推进」查看或编辑分段提示词，并用最终请求预览核对实际装配。
4. 回到聊天正常对话。每轮回复后去「变化」查看回执；遇到跳过或失败去「日志」查看错误码与恢复建议。

不配置推演 API 也能查看地图、时间、附近人物及路线预览；自动推演和 AI 尺度估计需要已配置的连接。

正式聊天使用 SQL 统一管理地点、人物、物品、地图与后台结算。新安装默认开启 SQL；明确关闭时暂停推演并保留存档。只有宿主确认保存后才发布新修订，地图与附近页按实际快照刷新。旧世界和三表只作一次迁移输入与恢复备份，不持续反向同步。Leaflet 地图实验台验证动态网格、层级与人物聚合，尚未替换正式地图渲染器。

世界数据随聊天会话保存；导出世界 JSON 可用于备份。旧预设的原始数据若已丢失且无备份，程序无法凭空恢复其正文。真实 SillyTavern 中的交互和旧档升级请按实机验收清单检查。

## 更新与卸载

- 更新：扩展管理里更新本仓库后刷新页面。
- 卸载：扩展管理中停用并删除。已写入的世界书条目保留在角色卡世界书（或 Atlas 专属书）里，不需要时可在酒馆世界书管理里删除；聊天里的世界绑定数据随聊天删除而消失。

## 进阶形态

提供可选的 Server Plugin 形态（世界数据落服务端文件、文件级数据安全），见 [`atlas-server-plugin/README.md`](./atlas-server-plugin/README.md)。常规使用无需安装。
