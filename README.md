# 阿特拉斯 / Atlas

SillyTavern 世界引擎扩展：把一张**会随剧情推进的世界**带进你的酒馆聊天——地图、世界时间、周边 NPC、事件触发，以及每轮回复后的世界推演。

**纯浏览器形态**：世界引擎整体打进 UI 扩展，安装后零配置、零服务端依赖。推演 API 密钥只存在浏览器侧，经酒馆自带后端代理转发，不落任何服务端。

## 功能

- **世界工作台（悬浮窗）**：按住顶栏可拖动的居中窗口，左栏导航 + 中央页面 + 右栏世界变化简览。
  - **概览**：世界名、分支、当前位置、世界时间。
  - **地图**：地区筛选、物件标记、路线预览（确认后只填入输入框，绝不自动发送）、缩放；**地图自动生长**——首次推演自动从世界书 / 剧情提炼建图，此后每轮推演自动把剧情新出现的地点上图，无需手动提炼；**点挂子图**——点击标记点弹出简略信息面板，楼 / 院落 / 遗迹类地点内含子图（网格 + 内部点位 + 独立比例尺），最多四层、面包屑逐层返回；玩家在建筑内部时「定位当前位置」会回溯到实际所在的建筑。人物不在地图上叠标点，改由地点名单承载（见「附近」）。
  - **附近**：只列出引擎判定的相关人物与命中原因（同地点 / 附近 / 同地区 / 路线 / 日程等）；人物目录中不相关的成员仍可在其所在地点的名单里查看，玩家角色不会冒充「附近 NPC」。
  - **变化**：每轮世界推演回执时间轴 + 失败重试 + 世界书条目面板。
  - **推进**：查看内置 v2 提示词与最终请求预览；按角色、名称、正文编辑分段，排序、保存副本、导入和导出提示词预设；用「检查当前世界」预览旧起点修复，并备份或恢复 Atlas 会话。
  - **API**：配置和切换推演连接，独立保存密钥与模型参数；连接级系统提示词覆盖会在推进页提示。
  - **替换**：管理可选的思考段清理规则和地图外观。
  - **日志**：按聊天与回合查看安全诊断时间线，筛选、搜索、复制摘要、导出 JSONL；可主动开启最多 7 天的本地脱敏归档。
  - **概览中的世界管理**：绑定 / 解绑、导入或导出世界 JSON；未绑定时可自动建立空地理新世界。
- **生成前注入**：发送消息后，自动把有界的世界上下文（当前地点、时间、相关 NPC）挂入本轮生成，不写入可见聊天历史；酒馆内部静默生成（总结、向量索引等）不会误触发。
- **回复后推演**：最终回复完成后推演世界变化，原子写入世界账本（时间、地点、NPC 状态、记忆），失败不阻断酒馆聊天、可重试、幂等不重复推进。
- **swipe / 编辑 / 删除与世界同步**：每次推演自动落检查点；删除、编辑或右滑重新生成最近一条回复时，世界自动回退到该回合之前，新变体作为**同级结果**重新推演（时间不累计），历史保留可追溯。
- **推演结果写入世界书**：自动生成「NPC 动向」「近期可触发事件」条目（关键词 = NPC 名 / 地点名），优先写入**当前角色卡的世界书**（随角色激活，不占聊天绑定槽）；角色卡无世界书时回退 Atlas 专属书。
- **多聊天隔离**：绑定信息只写入当前聊天的 `chatMetadata`，A / B 聊天互不串线。

## 安装

1. SillyTavern ≥ **1.12.0**。
2. 在 SillyTavern 扩展管理里点「Install extension」，粘贴本仓库链接。
3. 刷新页面，扩展菜单出现「阿特拉斯 / Atlas」。

没有服务端组件、没有配置文件——装完即玩。也可以手动把仓库内容复制到 `data/<用户>/extensions/` 下的扩展目录。

## 快速上手

1. 点扩展按钮打开世界工作台。
2. 在「概览」绑定已有世界，或建立空地理新世界；需要时可导入世界 JSON。
3. 在「API」配置端点、密钥和模型名；在「推进」查看或编辑分段提示词，并用最终请求预览核对实际装配。
4. 回到聊天正常对话。每轮回复后去「变化」查看回执；遇到跳过或失败去「日志」查看错误码与恢复建议。

不配置推演 API 也能查看地图、时间、附近人物及路线预览；自动推演和 AI 尺度估计需要已配置的连接。

世界数据随聊天会话保存；导出世界 JSON 可用于备份。旧预设的原始数据若已丢失且无备份，程序无法凭空恢复其正文。真实 SillyTavern 中的交互和旧档升级请按实机验收清单检查。

## 更新与卸载

- 更新：扩展管理里更新本仓库后刷新页面。
- 卸载：扩展管理中停用并删除。已写入的世界书条目保留在角色卡世界书（或 Atlas 专属书）里，不需要时可在酒馆世界书管理里删除；聊天里的世界绑定数据随聊天删除而消失。

## 进阶形态

提供可选的 Server Plugin 形态（世界数据落服务端文件、文件级数据安全），见 [`atlas-server-plugin/README.md`](./atlas-server-plugin/README.md)。常规使用无需安装。
