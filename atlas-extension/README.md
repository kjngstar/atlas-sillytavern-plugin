# 阿特拉斯 / Atlas — UI Extension

SillyTavern UI 扩展：**世界工作台（悬浮窗）** + 聊天绑定 + 生成前注入 + 回复后世界推演 + **推演结果写入世界书**。

**0.7.0 起为纯浏览器形态：引擎核心整体打进本扩展，安装后零配置、零服务端依赖。**扩展内不存储任何密钥到服务端（推演 API 密钥只存在浏览器侧，经酒馆自带后端代理转发）。

## 环境要求

- SillyTavern ≥ **1.12.0**（依赖 manifest `hooks.activate / hooks.disable` 生命周期、`generate_interceptor`、`setExtensionPrompt`、`getRequestHeaders`、世界书公开 API）。
- 现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）。
- **不需要**安装任何 Server Plugin。

## 安装（单步）

1. 在 SillyTavern 扩展管理里点「Install extension」，粘贴发布仓库链接（或把 `release/atlas-ui-extension/` 整目录复制到 `data/<用户>/extensions/atlas-extension/`）。安装包自带构建产物 `dist/atlas-ui-core.mjs`，**不需要**也不允许引用目录外的源码。
2. 刷新页面，扩展自动激活（manifest `hooks.activate`；旧版无 hooks 时模块加载即幂等自初始化，不会重复监听），扩展菜单出现「阿特拉斯 / Atlas」。

没有服务端组件、没有配置文件——装完即玩。

## 使用（真实首用流程）

- **最快开始**：安装并启用后，直接打开任意角色卡、**发出第一条消息**——阿特拉斯会自动创建以角色命名的最小世界并绑定（无需导入任何 JSON），随后每条消息自动推演世界。不想自动建世？设置页也可以「一键创建演示世界并绑定」或导入自己的世界 JSON（备用路径，入口在「设置」页）。
- 点扩展按钮打开**世界工作台**：居中悬浮窗，按住顶栏可拖动，随时「退出」回聊天。
- 左栏（导航 + 世界动向），固定六项：**概览 / 地图 / 附近 / 变化 / 推进 / API**。
  - **概览**：当前世界卡（未绑定说明、自动初始化状态与「重试初始化」、启用 / 停用本聊天推演）+ 世界状态统计 + 底部默认折叠的「高级：迁移或恢复已有世界」（世界列表 / 导入 JSON / 解绑）。
  - **地图**：地区筛选、NPC 金色圆点、物件菱形标记、路线预览（确认后只填入输入框，绝不自动发送）、缩放。
  - **附近**：相关 NPC 与命中原因（同地点 / 附近 / 同地区 / 路线 / 日程等）。
  - **变化**：每轮世界推演回执时间轴 + 失败重试 + **世界书条目面板**（Atlas 动向 / 近期可触发事件）。
  - **推进**：只管理推进行为与提示词——启用 / 停用、自动提交开关、**提示词多预设**（新建 / 保存 / 另存为 / 设为当前使用 / 删除 / 复制内置默认）、只读的「当前生效提示词」。**这里不配置 API 地址**。
  - **API**：只管理连接资料——多连接预设（新建 / 保存 / 另存为 / 设为当前使用 / 测试连接 / 删除）、端点 / 密钥 / 模型 / 参数、从端点读到的模型列表。**这里不编辑提示词**。
  - 两页各自维护未保存草稿，互不覆盖；跨页切换不丢草稿，只提供只读摘要与「前往…」跳转。
- 右栏 = **世界变化简览**：最近几轮推进的状态圆点与摘要，一键跳「变化」页。
- 生成前注入：发送消息后 prepare，生成拦截器把有界世界上下文挂入本轮生成（临时上下文，不写入可见聊天历史）。
- 回复后推演：最终回复完成后 commit（进程内派发，零网络）；**推演结果自动写成 Atlas 专属世界书条目**——「NPC 动向」关键词 = NPC 名、「近期可触发」关键词 = 地点名，主模型经酒馆正常世界书激活管线看到，关掉插件条目仍生效。聊天未绑定世界书时自动绑定 Atlas 书；已绑定别的书则不覆盖，只在变化页提示。
- 绑定信息只写入当前聊天的 `chatMetadata.atlas_binding`（契约 AtlasChatBinding 形状，无任何密钥字段）；切换聊天立即重新读取，A / B 聊天互不串线。

## 更新与卸载

- 更新：用新版目录覆盖安装目录（或扩展管理里更新仓库）后刷新页面。
- 卸载：在扩展管理中停用并删除目录；停用（`hooks.disable`）会清理面板 DOM、事件监听、菜单、拖拽监听与全局生成拦截器（停用后宿主普通生成完全不受影响）。已写入的世界书条目保留在 Atlas 专属世界书里，可整书删除。

## 版本

- 0.9.23：**世界书资料开关（审核拦截逃生门）**——推进页新增「关闭 / 开启世界书资料」：如果推演被供应商内容审核拦截（MiniMax 422 unprocessable / new_sensitive），关掉它 = 推演不再附带卡书条目（回到 0.9.20 前的上下文），立刻能继续玩；代价是推演看不到卡内设定。默认开启。
- 0.9.22：**推演被审核拦截给出人话 + 推进页「立即推演」按钮**——①MiniMax 等供应商对输入做敏感内容检测（HTTP 200 包 422 unprocessable_entity / new_sensitive）：此前报错会误导你去查模型名，现在明确提示「内容审核拦截，重试同样被拦，换模型 / 供应商或调整文本」并附原始错误；②推进页新增**「立即推演」**：不发言也让世界流动——合成一回合（固定占位行动 + 最近楼层正文作素材 + 世界书资料），带确认弹窗防误触，每按一次推进一回合（时间流动、NPC 日程结算）。
- 0.9.21：**推演读世界书了（抄 shujuku 读卡书思路）**——此前推演 AI 只能看到 Atlas 内部状态（自动建世=起点+主角），完全不知道你角色卡世界书里写了什么，等于盲推。现在每次推演前自动读当前角色卡世界书（卡主世界书优先，聊天绑定书回退，ST 原生 world-info API）的启用条目，变成有界资料块（单条截 400 字、最多 60 条、总量 6000 字）喂给推演模型。细节：Atlas 自写的「动向 / 事件」条目不回喂（防复读）；资料只进推演请求、不进主聊天注入（主聊天由酒馆世界书激活管线负责，不重复）；书不存在 / API 不可用 → 静默降级照常推演；分段预设可用 `{{worldLore}}` 占位符自定位置（默认塞在「当前世界状态」之后）。这一版大概率能顺带减少「校验失败」——模型不再凭空编造它看不见的世界。
- 0.9.20：**校验失败原因接线到日志页 + 变化页失败回执全文 + 地图空地理诚实提示**——①「回合提交失败」不再隐形：200 信封里装着失败回执时，日志页现在会记一条红色 `回合提交失败 → <完整原因>`（此前只记一行 `POST /turns/commit → 200`，原因查无可查）；②「变化」页失败回执整卡标红并展示完整 summary（此前截 70 字正好把「失败原因：…」剪掉）；③地图只有「起点」一个点时显示底部诚实提示：自动建世只创建起点，推演管线暂不能生成新地点（AI 生成地点在后续版本规划中）——单点地图是数据如此，不是渲染坏了。
- 0.9.19：**推进页重做（完全对齐 shujuku presentation-v2 样式）**——分段编辑器从折叠区升级为常开分区：每段带 `#序号`（mono）+ 角色下拉 + **上移 / 下移**（新增，可自由调段序）+ 删除按钮，正文全宽 textarea；分段之间细分割线，新增「在最上方插入一段」「在最下方插入一段」居中按钮与居中空态提示；头部动态状态（已启用 n 段 / 未启用）。数据契约与 0.9.18 完全一致，老分段预设无损。
- 0.9.18：**分段提示词（shujuku prompt-builder 同款长段多角色预设）+ 提示词后处理默认严格 + 按连接 System Prompt**——①提示词预设可升级为**分段模式**：每段自选角色（system / user / assistant）+ 正文，最多 16 段，正文支持 `{{worldState}}`（世界状态上下文）/ `{{userAction}}`（本轮用户行动）/ `{{assistantReply}}`（本轮助手回复）占位符，发送时逐段替换装配成完整消息数组；≥1 段时取代单条正文，输出契约不变（模型仍须只输出一个 JSON 对象）。推进页编辑器新增「分段模式」折叠区，预设下拉标注「（分段 n）」；②「提示词后处理」默认值对齐 shujuku：缺失 / 非法 → **严格**（强制对话角色交替），显式选「未选择」仍为原样透传；③API 页新增**按连接 System Prompt（可选）**：本连接专用的系统提示词，三种连接方式都生效，填写后优先于「推进」页提示词预设。
