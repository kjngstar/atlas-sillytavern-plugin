# Atlas 酒馆扩展

常规安装直接使用仓库根安装单元，见 `../README.md`。本目录是由工具同步的组件镜像。
复制发布包时必须包含 `index.js`、`ui/`、`dist/`、样式、设置和 manifest，WASM 在 `dist/vendor/`。

正式流程以当前聊天 SQL 数据库为唯一写入目标，正文完成后推演，正文生成前仅注入主角可接触的场景和线索。
旧世界/三表自动迁移一次并保留原档；SQL 关闭时暂停，不恢复旧执行器。
地图支持逐层下钻、房间边界、人物/物品标点、各层独立相机和人工纠偏。布局估计不作为实际距离。

提示词条目可增加、改角色、编辑、排序、启停、导入与导出；SQL 默认预设使用统一语义操作协议。
自定义原预设保留原文，冲突协议有明确迁移提示。地图实验台尚未替代正式渲染器。

开发与验收边界见 `../src/README.md`；施工记录见 `../docs/atlas-architecture-cleanup-progress.md`。
