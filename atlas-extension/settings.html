阿特拉斯 / Atlas
Atlas 把 Atlasia 的世界地图、世界时间与附近 NPC 带进酒馆。 请先安装 Atlas Server Plugin，然后在聊天中通过阿特拉斯面板绑定世界。
独立推演 API 预设与密钥只保存在服务端插件设置中，浏览器端永远不会存储或回传密钥。
开启后地图 / 附近 / 日志改从 SQL 世界库读取（同一时刻只有一个读权威，不再读旧三表投影）； 关闭时完全沿用旧路径。 设置键：extensionSettings.atlas_world_sim.sqlWorldDataEnabled（缺省 false）。 SQL 核心（dist/atlas-sql.mjs，含 sql.js + wasm）只在开启后才加载；加载失败会在面板上 显示具名诊断并退回旧路径，不会静默假装已启用。
