## 2. 本次内容

### 2.1 采用外部工作线的交接包（主要变更）

来源：另一条工作线（`cleanup/remove-legacy-turn-protocol` 未提交快照）的
`changes-from-806a0fd.patch`。采用方式为 `git apply -3` **三方合并**，
并按 patch 与交接说明逐文件核对；**没有整树拷贝**（上一轮整树拷贝曾做成半合并状态）。

| 项 | 内容 |
| --- | --- |
| 废弃代码清理 | 删除 `src/atlas-turn-v2.ts`、`src/atlas-contract-v2.ts`、`src/atlas-adjudicate.ts`，以及 5 个只验证废弃协议 / 已删符号的测试文件；`src/atlas-turn.ts` 文件内精简 330 行 |
| 引文纠错 | `repairQuoteOnlyReply`：零有效行、且拒绝项全由引文或依赖错误组成时，发起**一次**有界模型纠错；仍失败则不写世界、不推进时间。调用点在首次引导与每轮提交 |

| 视口网格 | 网格改为随相机计算的淡色 SVG 路径（`extent="viewport"`），铺满视口、放大仍清晰 |

### 2.2 日志页「详细模式」（作者需求）

作者原话：「日志能不能写完整一点，现在在开发阶段，失败了要写，成功了**每一条也要写**，
这样我们就知道哪里成功，哪里失败了。」交接包只覆盖「失败写清楚」，本次补齐成功侧。

- **默认精简**：折叠信息级高频成功噪声——引擎每次 dispatch（`API_CALL_COMPLETE`，含每轮
  `/state` 轮询）、模型每次请求（`MODEL_HTTP_COMPLETE`）、重复回合（`TURN_DUPLICATE`）。
  正常操作下 `/state` 会把日志刷屏，故默认不显示。
- **详细模式**：日志页一个开关，打开后**一条不筛**，成功链逐条可见。
- **边界（重要）**：任何 `warn` / `error` **在任何模式下都不折叠**；折叠条数在页头如实报出
  （「精简模式已折叠 N 条成功噪声……」），不静默。
- 偏好持久化于 `localStorage`（`atlas:log-detail-mode:v1`）；隐私模式下退化为本次会话有效。

2. **`atlas-release-audit.test.mjs` 的发布包扫描存在并发假失败。** 它与
   `atlas-integration.test.mjs` 并行跑，后者会 `execFileSync` 跑 `tools/pack.mjs` 清空并重建
   `release/`；若扫描在 walk 之后读到被删文件、或在重建窗口内 walk 到空目录，会以
   「发布包存在」/「实际扫描文本文件 N 个」**大声失败**。脚本已有 3 次重试（只对「读不到文件」
   生效），但**重建窗口内的空目录不在重试覆盖内**。实测概率：本次 5 次运行中 1 次假失败。
   **风险等级：仅假红，不会假绿**——真违规（密钥形态串 / 本地绝对路径 / 临时文件）在任何一次
   尝试中都会让断言失败。修复方向：把 walk 也纳入重试，或让审计用例与 pack 串行。

## 6. 0.9.60.1：作者实测后的两处界面修复

作者在真实酒馆装 0.9.60 跑通一轮后反馈两点，均已修复（纯 CSS，不改数据与协议）：

1. **顶端工具条挤在一起。** 根因不是字号，是 **flex 压缩**：`.aw-maptools` 过去是固定单行 +
   `justify-content: space-between`，子项默认可收缩（`flex-shrink: 1`），面板一窄就把子项压到
   缩不下去为止——「叠加 / 网格 / 底图」逐字竖排、下拉框走 `text-overflow: ellipsis` 截断。
   现改为 `flex-wrap: wrap`（放不下就换行，**不挤压**）+ 子项 `flex: 0 0 auto` +
   `justify-content: flex-end`（原写法把中间项硬推到面板中央），视图按钮加
   `white-space: nowrap` 并把内边距 4px 10px 调到 5px 12px。
2. **缺坐标地点的名牌是斜体。** 删除 `.aw-point--displayonly` 的 `font-style: italic`。
   H08 原意是「与确认坐标一眼可分」，而虚线边框 + `opacity: 0.72` + 「待定位」角标已经足够；
   中文没有真正的斜体字形，浏览器合成伪斜体在 12px 下明显发虚。旁证：相邻的
   `.aw-point__pending` 本就写着 `font-style: normal`——当初已觉得斜体不对，只是没删父级那行。

**为什么另发 0.9.60.1 而不是覆盖 0.9.60**：这样作者在酒馆里看到版本号变化，就能确认文件真的装进去了
（只改 CSS 时版本号不变，无法分辨「装上了」和「还是旧的」）。

**发版过程中被自己的防护拦下一次（如实记录）**：bump 根 `index.js` 的 `ATLAS_EXTENSION_VERSION`
时漏了同步镜像，`npm run pack` **拒绝执行**并报
「atlas-extension/index.js 镜像与根 index.js 不一致」，`npm test` 随之 3 条转红
（manifest 版本一致 / P0-01 / 版本一致性）。同步镜像后全部恢复。
**这条防护有效**——它挡住的正是 0.9.59 那轮真实发生过的漏改。

验收（实跑）：typecheck 0 错误；`npm test` **883 / 883 通过，0 失败，0 跳过**；
build / pack OK（`index.js mirror in sync`）；`git diff --check` 干净；
`index.js` 与 `style.css` 两处镜像均逐字节一致；`release/` 内版本为 0.9.60.1。

**仍未做**：未定位标点仍按边栏格子逐格摆放（`src/atlas-map-layout.ts` 的 `slotCell`），
而名牌是 `white-space: nowrap`、宽度随名字长度变，因此名字一长仍会互相压住
（作者截图里的「枫叶城郊外野」被压住即此）。修法是**按渲染宽度做矩形避让**，
属算法改动 + 单测，作者已确认放到后续一轮。
