# Atlas 0.9.100

发布日期：2026-10-29（Asia/Shanghai）。本版本合入地图修复 PR #10 和面向使用者的 README PR #7。

## 地图变化

- 世界、地区图只有少数分散地点时，默认适应视野使用更紧凑的统一缩放，比例尺随实际相机比例更新。地图坐标、物理距离、米/格与存档几何保持原值；未标定地图继续显示格。密集地图、城市与丰富地形继续使用通常取景。
- 子图使用自己的坐标系，远方兄弟地图不会扩大本图取景。地点按真实父子关系导航，连续场所和载具不再依赖固定层级编号。
- `near` 与方位一起使用时，按参照地点的方向局部排位。建筑碰撞检查包含矩形四角和自然轮廓的完整范围，避免中心距离合格但轮廓重叠。
- 循环邻近关系从实际环内地点起排，避免排序更早的外部依赖被放到地图另一侧。验收夹具中原本相距约 4807 米的邻近地点，修复后相距约 15.5 米。
- 确认位置和符合结构签名的既有布局继续保留。相机取景调整会作用于旧图，布局排位修复在新生成或结构变化时生效，不会自动搬动已保存地点。

## 内容与说明

- 移除地点集合、房间、陈设、操作行、预设数量和长文本等缺少依据的截断；整体输入字节、路径复杂度和导航预算继续校验，非法引用仍会拒绝。
- README 按安装、快速上手、地图与皮肤、备份和常见问题组织，并同步正式版本与下载入口。
