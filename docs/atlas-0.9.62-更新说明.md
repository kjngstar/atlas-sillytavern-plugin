# Atlas 0.9.62 更新说明

本次从仓库 `b0aa9cc`（0.9.61）核对并修改，合入交接包中适用于已应用上一阶段补丁的增量版本。

## 场景和位置

- 默认推演提示词每轮根据正文、前文和明确的主角 ID 判断已抵达地点。唯一明确的上下文推断可以使用 `basis="inferred"`，无需编造逐字引文，界面显示“剧情推测”。
- 意图、梦境、回忆、远方镜头和在途不算抵达。远方 NPC 的推测意图不能直接改成当前位置；位置行被拒时仍保留合法的独立想法和目标字段。
- 主角人物表中的位置是场景投影的依据。未知位置保持未知；手动纠偏入口放在地图的“作者确认”折叠区。推测不会覆盖不同地点的手动记录，直接正文观察可以更新位置。
- 同地点已入表的人物不再因为旧相关名单缺失而漏显。其他地点的人物单列为“距离未定”，供作者查看。
- 地图保留地点卡、内部地图、面包屑和关闭操作，并补上人物与持有物品之间的跳转。

## 正文注入与世界书

新的动态上下文只走当前聊天临时注入，不再写入原生世界书；宿主注入失败时也不回退写书。同步时清理旧 Atlas 自动生成的动态条目，保留用户静态设定。角色卡世界书资料仍可被后台推演只读使用。

后台账本保留完整推演状态，但正文上下文不会获得私下想法、未来行动、后台意图、全世界人物 ID 名单、未送达消息或其他接收者的知识。作者查看秘密或其他地点，不会扩大正文注入范围。

格式示例如下，仅表达投影结构，并非真实聊天内容：

```xml
<atlas_scene_context version="2">
仅用于续写当前视角；传闻不等于事实，不能把人物私下意图写成主角已知。
【当前场景】
位置链：遗迹 → 破败大厅
在场：少女
【场景线索】
此地可接触的风声（不代表已经注意或核实）：门外有人低声谈论库房的异常动静。
</atlas_scene_context>
```

没有场景或线索时注入为空。消息必须已经到达主角，或已经到达当前地点成为可接触候选；后者不会自动变成角色已知。SQL 模式额外使用已有的停留、明确看见／听见及路过节点依据，并排除私密、受限、未来和失效消息。投影本身不写认知。

切聊天、停止生成和静默生成会清理临时提示；生成前合并注入入口，避免同一段重复出现。旧聊天的迟到推演及上下文投影会核对作用域。回退后按当前会话重建临时上下文。

本次沿用临时提示词通道，未加入自动改写 assistant 楼层末尾的功能。

## 安装和验证

将安装包中的 `atlas-ui-extension` 目录内容替换到现有 Atlas 扩展目录，包含 `dist`，然后刷新酒馆页面。包内已带浏览器构建产物，不需要单独编译或安装服务端插件。

自定义提示词不会被自动覆盖。使用自定义预设或连接级系统提示词时，请在“推进”页检查是否仍要求所有人物位置都必须逐字引用；需要新位置判断规则时，切换到当前默认行增量预设或同步修改自己的规则。

已完成：类型检查、完整 1284 项测试（全部通过）、自包含发布包重新构建。测试包括位置推断、手动纠偏保护、远方人物移动拒绝、后台隐私过滤、公开消息接触门槛、聊天切换、回滚以及人物／物品卡跳转。

尚未在用户的真实酒馆聊天与模型服务中验证。交接说明中的世界书地理持续导入、估计地图布局和更完整的空间关系推断仍属于后续工作。
