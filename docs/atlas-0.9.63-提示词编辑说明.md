# Atlas 0.9.63 提示词条目与预设

本版继续包含 0.9.62 的场景位置判断、附近人物与场景线索临时注入修改；新增可直接操作的提示词条目编辑器。

## 使用方式

1. 打开工作台的「推进」页。提示词编辑器已移到页面前部，保存操作条会随编辑区滚动保留。
2. 使用默认规则作为起点时，点「复制内置默认为新预设」。副本保存到预设库后即可编辑；原内置默认保持只读。
3. 每个条目可以改名称、消息角色（system / user / assistant）、正文、槽位标注与启用状态；上下移动改变发送顺序，复制条目在原条目后插入副本。顶部和底部按钮可以添加空条目。
4. 停用条目仍随预设保存、另存为和导出，模型请求跳过该条目。受预设保护的条目可修改或停用；复制出的副本可删除。
5. 修改已保存预设时，保存会更新该预设。新建、复制或导入的新预设需在保存后从下拉中选择，才能启用。编辑区会分别标明实际使用的预设与正在编辑的草稿。
6. 最终请求预览使用当前世界和**已保存且启用**的预设，不调用模型。它不会预览未保存草稿。连接级系统提示词覆盖预设时，会在编辑区顶部提示并提供清空入口。

角色指消息的 system / user / assistant 角色。故事人物设定可以写在条目正文中，或通过 `$U` / `$C` 引入。主槽位 A / B 仅是标注；实际发送顺序始终按列表顺序。

最多 16 个条目，每条最多 8000 字。空正文在保存时剔除；分段预设至少启用一个非空条目，否则保存失败，草稿保留。旧损坏配置若全部停用，发送会停止并说明原因，避免静默改发默认提示词。

## 导入、导出

支持 Atlas 的 `atlas-prompt-pack@1` JSON，以及 shujuku 导出的预设数组或单个含 `name` / `promptGroup` 的对象。文件最多 512 KiB，按 UTF-8 字节计算，允许最大合法中文分段包完整导回。

导入先载入可编辑草稿，不自动写设置、不覆盖已有预设、不自动启用。文件包含多份预设时，可选择其中一份，修改后保存；重名会生成新的名称。只有任务级 `plotTasks[].promptGroup` 的文件会按任务分别供选择，多个任务不拼接。顶层 `promptGroup` 存在时优先使用，避免重复导入任务镜像。

兼容大小写消息角色、`enabled`、`deletable`、`name`、`mainSlot` 和旧 `isMain` / `isMain2` 槽位标记。只导入提示词字段与上下文条数；不会迁入 API 设置、密钥、任务链、召回规则或世界书选择。编辑器入口对无效角色、过长内容和过多条目整份报错，避免悄悄丢弃部分内容。

shujuku 的任务正文不能直接作为 Atlas 推演协议使用。请把输出规则改成 Atlas 的 `<atlasEdit>` 行增量；其专用占位符和召回编码需按实际任务改写。`$5` 在 Atlas 中代表世界状态，不代表 shujuku 的纪要索引。

导出包含**当前编辑内容**，包括未保存的修改和停用条目，也支持导出内置默认。包不携带本地 ID、API 配置或密钥。

默认可导入样例：`examples/prompts/atlas-scene-default.atlas-prompt-pack.json`。它由本版真实内置六段规则生成，包含位置推断和行增量输出规则。

## 素材占位符

| 占位符 | 内容 |
| --- | --- |
| `$5` | 后台推演所需的世界状态 |
| `$1` | 世界书资料 |
| `$6` | 上轮推演结果 |
| `$7` | 前文 AI 楼层，预设配置最近 1–10 条 |
| `$8` | 本轮用户行动 |
| `$U` | 用户设定 |
| `$C` | 角色描述 |
| `{{assistantReply}}` | 本轮正文 |
| `$9` | 保留位，恒空 |

这些素材用于后台推演请求。对正文的动态注入继续遵循 0.9.62 的场景可感知范围，编辑条目不会扩大正文投影权限。

## 验证

类型检查与完整 1297 项测试通过；回归涵盖实际请求跳过停用内容、保存和重载、另存为、复制排序删除、多个外部预设选择、导入不激活、UTF-8 限额与最长名称重名。旧协议检测与兼容迁移也会跳过停用条目。

使用本地 Chrome 检查真实编辑器在 1440、900、390 像素窗口下的条目布局，无横向溢出。截图使用测试数据，没有真实聊天或密钥。尚未在用户的真实 SillyTavern 聊天中测试外部提示词的模型输出效果。
