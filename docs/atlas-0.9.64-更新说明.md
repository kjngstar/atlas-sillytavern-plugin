# Atlas 0.9.64

本版正式发布此前本地验证的场景与提示词修改，包含 0.9.62 和 0.9.63 的全部改动。

- 主角位置由默认推演根据正文和上下文判断，允许明确的地点推断；手动定位用于作者纠偏。
- 同地点已入表人物不会漏显。其他已知地点人物列为「距离未定」，不凭空断言在附近。
- 正文动态上下文只注入当前场景与可接触线索；后台意图、私下想法和未送达消息留在后台。无可用内容时不注入，动态状态不再写入原生世界书。
- 「推进」页前部可直接编辑提示词条目的名称、消息角色、正文、顺序与启用状态，支持复制、删除与预设副本。停用条目仍保存，实际请求、旧协议检测与兼容迁移均跳过。
- 支持 Atlas 包与 shujuku JSON 导入：多预设可选择，先载入可编辑草稿，保存后再启用；可导出当前编辑内容。shujuku 的任务正文仍需适配 Atlas 的 `<atlasEdit>` 行增量协议。
- 连接级提示词覆盖提示位于编辑区前部。最终请求预览明确使用已保存且启用的预设。

操作细节见 [提示词编辑说明](atlas-0.9.63-提示词编辑说明.md) 和 [场景与注入说明](atlas-0.9.62-更新说明.md)。默认预设样例为 `examples/prompts/atlas-scene-default.atlas-prompt-pack.json`。

发布验证：类型检查、1297 项完整测试和构建打包通过。编辑器已在本地 Chrome 的 1440、900、390 像素窗口检查布局。尚未在用户真实 SillyTavern 聊天中验证外部提示词的模型输出效果。
