# Atlas 0.9.65

本版将 0.9.64 之后的场景、世界书、地图与聊天隔离修复合入 `main`。在原有的 SillyTavern 8000 端口和原有 Atlas Git 安装目录中，已用专用测试角色验证两种题材的自动开场、两本各 120 条世界书的末尾条目编辑进入实际模型请求、普通回合提交、跨聊天隔离、窄屏三级地图点入及缩放、502 后重试成功，以及酒馆原生右滑的旧候选回退和新候选提交。

默认提示词现在明确区分「助手正文有事实证据」与「主角可知」：远方幕后镜头的行动可按逐字引文入表，是否呈现给主角由可见性规则另判。真实宿主的默认视图只显示同地伊莱恩的行动，作者视图额外显示远方塔尔的隐藏行动。信号提案的内置格式也明确为 `kind:"signal"`，没有实际发信事实时省略。

本版还修复了当前 SillyTavern 右滑时序：酒馆先把 `swipe_id` 指向数组外待填槽，生成后才追加 `swipes`；Atlas 现可识别该状态并回退旧世界回合。查看已有非空候选仍不触发回退。

已知验收限制：消息真实送达主角后的视图变化、载具在途、迟到请求在原聊天的最终回执尚未完成真实酒馆端到端测试。长正文模型请求曾在 120 秒超时；失败状态会保留可重试挂单。详细证据见 [合并前验收记录](integration-before-main-checkpoint-20260930.md)。
