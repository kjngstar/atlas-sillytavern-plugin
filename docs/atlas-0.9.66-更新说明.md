# Atlas 0.9.66：首建世界书地理与地图定位

新聊天首次建世后，Atlas 读取当前角色及聊天绑定世界书的启用条目，按最多 32 批、每批约 5500 字逐步提炼地区和地点。导入在后台进行，首轮正文不会等全部批次完成。普通回合的世界书选择与正文注入仍按当前场景和主角可知线索收窄；导入的远方地点不会因此直接进入正文。已有世界可点地图页「从世界书提炼地理」补导，按钮会先显示预计的模型请求批数。地点去重，达到 200 个地图地点上限时停止；中途切换聊天则停止当前导入，可回到原聊天手动补导。地点名能入表并不等于已经确认空间关系或格坐标，缺证据的关系仍待作者确认。

「定位当前位置」现在按当前图层实际渲染的标点居中：世界图定位根地点，内部图定位当前房间或其上层入口，正在看别的图层时回到主角所在的地图。没有确认格坐标时只对准虚线示意标点，提示实际坐标未确认。世界图和内部图使用一致的工具栏结构，内部图的地区栏改为当前图名，窄屏将工具栏与面包屑放在地图绘制区上方，避免遮挡按钮及地点。

验证：类型检查、完整测试与打包通过；8000 端口现有酒馆的专用验收聊天中，世界书补导 3/3 批，地图由 3 个已记录地点增至 5 个；390px 窄屏实际点击内部图定位，显示「教学楼」示意标点和未确认坐标提示。新聊天的首建自动路径也已触发，开场定位与正常回合提交成功。模型从世界书提炼出多少地点取决于条目内容与模型输出，不能保证每个地名都被识别；超出批次上限或中断时界面会报告。
