# Atlas 0.9.71

本版修复地图与楼层回退的一致性，并把最内层场景中的人物直接放到地图上。

- 自动地理补全的新增地点、父关系、地图元数据和扩展计数随对应楼层回退。已经回退楼层的迟到补全被拒绝；重新生成可以重新补全。
- `presence=left` 清除人物的当前位置和目标位置，地图投影也过滤旧存档中的离场人物；人物档案与历史继续保留。
- 房间和街道等最内层场景可显示人物与地面物品的估计标记，取消右侧浮动名单。场景边界和主角标记使用 📍。
- 估计坐标按实际子地图格数缩放，默认布局按人数调整，不再每 16 人循环重叠。精确坐标物品只绘制一次。
- 工具栏、面包屑和绘图区各自占位，保留现有纸面地图风格。
- 默认提示词增加 `positionHint`：先根据正文建档和确认地点，再独立推测场景内方位。推测位置不会写入真实格坐标，也不用于旅行距离。正文和自动补全提示词都要求复用同一场景的既有地点，自动补全额外接收当前场景身份与描述。

## 验证

类型检查、打包和完整测试均通过：**1357 / 1357，无跳过**。

回归测试覆盖自动补全后回退及重生成、离场过滤和恢复快照、12×8 等不同尺寸房间、20 / 50 人布局，以及估计和精确坐标物品去重。真实 Chrome 在 1280 和 540 像素宽度下检查了 50 人场景：50 个标记均能直接点击，没有标记重叠，工具栏与面包屑不遮挡绘图区。

酒馆实测使用原来的 `127.0.0.1:8000` 和原 Atlas 插件，在已有专用验收聊天中普通发送消息，并调用真实模型。新人物周叔、小陈已建档并复用小巷 `loc:14`，分别显示“巷口”“左侧墙边”的估计标记。实际正文随后进入教室，主角正确复用既有 `loc:9`；地图可沿城市—学校—教学楼—教室导航，教室显示主角、场景边界和示意陈设。窄屏复查无导航遮挡。真实楼层回退也执行成功。

实测中有一条 `QUOTE_NOT_FOUND` 被校验拒绝，未写入错误更新；模型提炼并不保证每一行都能通过。上述验证证明本版修复及这些具体场景通过，不表示所有角色卡和模型的推断都已全面验收。旧版已经产生且未记录回退快照的自动补全残留，不会由新回退机制自动追溯修复。

原插件通过 Git 快进更新，仍保留原仓库和远程地址，可以继续用酒馆的 GitHub 更新功能。没有另装测试插件，也没有启动第二个酒馆实例。
