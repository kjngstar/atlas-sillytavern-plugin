# Atlas 0.9.73

按照作者要求撤掉自动条目类别排除与背景关键词摘录。角色卡、人设、前文和世界书仍作为原始资料进入请求；不按文风、思维链或是否命中地理关键词删掉内容。绑定世界书的启用条目按来源顺序传输，不再按宿主激活状态或关键词挑选。保留作者禁用条目的设置，仍排除 Atlas 自己生成的世界书内容，避免循环回喂。

默认推演提示词参考 shujuku 的分段模板，划分为职责与协议、当前状态及 ID、角色与世界背景、连续性材料、本轮行动及实际结果、提交前核对六段。任务职责与来源文本分开装配；模型依据当前正文优先于历史和背景，按核对证据、复用实体、判断位置、生成增量、校验引文的顺序更新状态。资料里的写作命令和输出模板不改变 Atlas 的任务或协议。仍使用当前的 `<atlasEdit>` 行增量，不引入上游不同的 SQL 和多代理协议。

新增 `{{source:$C}}` 等来源占位符，替换值按 JSON 字符串无损编码。模型先解码再读取资料，quote 复制解码后的连续原文。引号、换行、标签及原文里的占位符字面量都可还原，且不会二次展开。现有 `$C`、`$1`、`{{assistantReply}}` 等占位符保持兼容；自定义预设不自动覆写。

地理提炼与场景补全同样拆开职责、任务契约、原始资料。首次建图不做内容筛选；长世界书条目按批次长度拆分，移除原先每条 2500 字的截断，保留换行和后文。现有请求预算仍有效：普通回合世界书最多 6000 字，首次建图每批最多 5500 字、最多 32 批；超过预算会记截断，不声称无限量读取。地理提炼输出上限为 8192 tokens，普通推演仍使用作者配置的上限。

可导入试用预设位于 `presets/atlas-shujuku-structure.json`，包含六个可编辑、启停、改角色及重新排序的条目，不包含连接或密钥。它与新的内置默认采用相同结构；导入后由作者选择启用。

推演等待修复：正文生成期间显示等待正文，读取资料、排队、实际推演分别显示对应阶段；资料读取有 10 秒截止时间，模型请求和响应体读取遵循预设超时，即使宿主忽略取消信号也能退出。正文结束却未取得本轮助手楼层时清理等待，上一轮旧正文不会被再次提交。重复完成通知不会并发提交；上一轮附加场景补全尚未结束时，下一轮通知排队处理，不再被当作重复通知丢弃。被服务商拒绝的回执结束忙碌，不自动反复重试。

参考 [shujuku 90df4d7 的默认提示词结构](https://github.com/AlbusKen/shujuku/blob/90df4d79a20c54892709133ea0bf3c0cb2ea5d82/src/service/simulation/agent/agent-defaults.ts) 和 [模板装配](https://github.com/AlbusKen/shujuku/blob/90df4d79a20c54892709133ea0bf3c0cb2ea5d82/src/service/simulation/agent/prompt-template.ts)。这里借鉴结构与资料边界，不替换 Atlas 的数据协议。
