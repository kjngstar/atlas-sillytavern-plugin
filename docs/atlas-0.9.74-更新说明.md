# Atlas 0.9.74

地图中的建筑内部区域现在可以直接点击，打开对应地点详情；未确定精确坐标的房间也沿用已有建筑布局展示。房间边界随缩放保持稳定的屏幕线宽，悬停和键盘聚焦时显示区域反馈，沿用现有皮肤。

修复进入房间再返回上层时丢失平移和缩放的问题。每张地图保存自己的视角；工具栏、面包屑或窗口尺寸变化时重新适配视口，保留地图中心和相对缩放。切换聊天、世界或分支仍清理对应缓存。

新增独立的 Leaflet CRS.Simple 地图验证页，验证 Atlas 网格与平面坐标转换、多层地图切换、按缩放调整网格密度，以及 50 人重叠标点的聚合和展开。展开偏移只用于展示，不写回人物位置。Leaflet 和 markercluster 仅用于开发验证，尚未替换插件默认地图渲染器。

使用用户原有的 8000 端口酒馆、原插件和已有验收聊天完成实测：六个房间区域可点击，教学楼与教室往返保留视角，主角定位、室内陈设和街道人物可访问，1280px 与 540px 窗口操作正常。未生成新正文或调用模型，验收聊天文件保持不变。

发布验证：类型检查、构建与打包通过；完整测试 1382/1382 通过，无跳过。独立地图验证及真实酒馆验收结果见 [地图参考验证](atlas-map-reference-validation.md) 和 [本地酒馆验收](atlas-map-local-host-validation.md)。
