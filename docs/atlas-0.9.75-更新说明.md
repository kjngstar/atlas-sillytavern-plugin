# Atlas 0.9.75

当前聊天的 SQL 世界库现已接通正式初始化、推演提交、保存、重试、删楼回退和快照刷新。地点、人物、物品、地图、时间与后台事件统一从同一份数据库写入和查询，旧 world／三表资料保留作迁移和备份，退出重复写入。新安装默认启用 SQL；作者明确关闭时暂停推演并保留存档。

修复真实发布目录的 WASM 加载和会话快照缓存失效问题。每轮提交接入时间结算、沿途行动、人物后台行动与消息传播；短对话可以不推进时间，未送达消息与私密状态仍留在后台。失败重试使用原回合记录，回退恢复该楼层的实体、地图和后台变化。

地图和附近统一读取当前 SQL 修订。多层场景、人物细部位置、地图边界与陈设、背景素材及路线预览接入正式数据链，修复地图刷新后空白和跨聊天旧结果覆盖。保留已有地图皮肤与操作方式，拆出会话守卫、SQL 视图缓存、场景适配、地图交互与服务路由，清理已确认无引用的代码。

现有自定义提示词保留，支持可编辑条目、角色、排序、启用开关和预设导入。推演请求与最终请求预览使用同一套装配逻辑；生成前只注入当前视角能够接触的场景和线索，动态状态不写回世界书。

发布验证：类型检查、构建与打包通过；完整测试 1470/1470 通过，无跳过。真实发布文件在浏览器和 Worker 中成功打开 SQLite 数据库。使用原有 8000 端口酒馆、原插件和专用验收聊天验证过真实模型提交、保存重开、删楼回退、多层地图交互和窄窗口显示。

完整施工范围和验收条件见 [架构验收记录](atlas-architecture-cleanup-progress.md)。
