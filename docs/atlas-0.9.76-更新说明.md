# Atlas 0.9.76

新世界工作台接入正式 SQL 数据与空间画布：星幕深色界面、地图层级树、世界摘要、人物／地点／物品目录、实体详情和事件时间线统一显示当前聊天的实际快照。

空间场景支持城市河道与多边形区域、室内房间与陈设的渲染。布局候选接入提交、回退与分支迁移；插件提供场景参数与约束，AI 提议经校验后由程序生成和保存，界面读取已保存结果。

修复目录详情空白、子地图入口失效、地图树切换路径、缩放与适配按钮未连接新画布，以及作者／POV 切换后残留旧数据。地点卡、双击与 Enter 使用统一子地图入口；切图保存各地图视角，实体定位连接真实标记。

## 安装与更新

- 已安装用户：在 SillyTavern 扩展管理中更新 Atlas，随后刷新页面。
- 手动安装：解压 `atlas-ui-extension-0.9.76.zip`，把 `atlas-ui-extension` 目录放入 SillyTavern 的扩展目录。安装包包含所需构建产物和 WASM，不依赖源码目录或 node_modules。
- `atlas-server-plugin-0.9.76.zip` 是可选服务端组件，纯浏览器形态无需安装。
- 保留已有聊天数据；更新前可用 Atlas 会话导出功能备份。
