# Atlas 0.9.77

直接接入用户提供的 `atlas-ui-source.zip` 原版界面，以 `atlas-ui-preview (2).html` 为视觉与交互对照。

## 本次变更

- 原版页面、配色、字体、侧栏、详情区、底部事件区、搜索面板和预设编辑器进入正式入口。两份 CSS 与字体保持原包字节一致。
- 原版地图渲染器读取当前聊天的真实 SQL 快照，支持已保存的城市河道、多边形区域、城墙、楼层、房间、门和家具。地点进入子图、面包屑、缩放、平移、小地图和图例沿用原版操作。
- 人物、物品、消息、任务、回执和诊断接入正式数据。作者／主角所知切换重新查询，并丢弃旧聊天和旧视角的晚到结果。未知位置与未知行程进度保留为未知。
- 原版 API 与分段提示词编辑器接入真实设置。新建、保存、导入、删除和任务绑定使用原子设置接口；失败保留编辑草稿。已有高级连接字段、上下文条数、段落顺序及停用字段保留。
- 未勾选记住的 API Key 只供当前页面运行使用；导出和界面偏好不含 Key。原版外观与交互偏好通过酒馆设置保存。
- 世界书读取和启停连接当前聊天与角色卡的真实世界书接口。
- 正式入口移除了约 7300 行旧面板代码。历史面板保留在测试夹具中供兼容回归使用。

插件提供实体、尺度和空间约束；AI 提出的布局参数经程序校验、生成和保存后，由原版 UI 读取并绘制。没有已保存布局时显示实际地图概览。

## 安装

在 SillyTavern 扩展管理中更新 Atlas，然后刷新页面。手动安装可解压 `atlas-ui-extension-0.9.77.zip`，将 `atlas-ui-extension` 放入酒馆扩展目录。安装包自带构建产物、字体与 WASM。

`atlas-server-plugin-0.9.77.zip` 为可选服务端组件；纯浏览器形态使用 UI 安装包即可。已有聊天数据继续保留。
