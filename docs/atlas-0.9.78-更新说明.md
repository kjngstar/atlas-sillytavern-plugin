# Atlas 0.9.78

修复原版 UI 与酒馆宿主的交互遗漏，保留原版 CSS、字体、配色与地图交互。

## 修复

- 从酒馆扩展菜单打开 Atlas 时，点击继续冒泡到酒馆的关闭处理，菜单不再残留在新工作台上。支持 Enter 和空格打开；关闭后再次打开恢复工作台键盘焦点。
- 「推演」页接回当前聊天的启用／暂停开关，保存至真实宿主绑定。停用聊天可重新启用；处理回合期间禁止切换。
- 「推演」页提供 API 连接、提示词、任务绑定和诊断的直接入口，显示当前聊天推演状态。
- 推演或初始化失败后保留错误原因；未建立世界时也能看到错误。初始化返回失败不再提示成功。切换聊天不携带上一个聊天的操作错误。
- 推演期间显示处理状态，阻止重复点击。没有活动聊天、SQL 开关关闭或聊天停用时给出状态。
- 修复新聊天首次保存前的 `SQL_SNAPSHOT_UNAVAILABLE`：界面通过正式只读入口读取引擎当前会话，不再要求先有保存快照。读取不调用模型、不保存数据库、不创建假快照。
- 修正日志查询名为正式 `diagnostics`，保留失败回合、校验路径、分组、尝试记录等完整结构。
- HTTP／模型失败即使没有落盘快照，也记录真实失败回执；成功回执保存原生提交分组与保存状态。回执详情过滤请求／响应正文与凭据。
- 底部「推演回执」与「推演」页都能展开本轮日志；回执可导出。立即推演时自动展开回执区，错误不会因界面读取失败被清空。

## 推演日志入口

地图底部「推演回执」显示成功／失败记录，点击「查看本轮日志」展开错误码、HTTP 状态、问题路径及提交分组等记录；「导出推演回执」导出当前聊天的回执详情。「推演」页也显示回执。左侧「诊断」包含更完整的诊断时间线。

## 设置入口

新工作台右上角滑杆按钮打开 API、提示词和任务预设；左侧「推演」页也能直接进入这些设置。左侧「诊断」可展开日志并导出。

「世界后台／主角所知」按钮切换信息视角。浏览器安装形态的引擎在酒馆页面中运行，SQL 世界数据随当前聊天保存；不要求额外运行 Atlas 服务器插件。

## 验证

- 类型检查、构建、打包通过。
- 完整测试 1617 项通过；总套件包含后端和历史兼容回归。
- Chrome 对实际安装目录的 59 项检查通过，无浏览器错误。新增菜单测试使用按 SillyTavern 官方菜单事件逻辑制作的隔离宿主；首次推演测试实际经过 SQL 模型端口，验证缺少 API 时生成详细失败回执，且不产生假快照。另有注入故障的显示测试，均未调用用户在线模型。
- 原版两份 CSS 和字体哈希保持一致。

用户截图中的界面快照读取错误已定位并通过无快照聊天复现修复。原先 AI 调用失败的具体原因仍需查看真实推演回执确认，不能把快照读取错误直接认定为模型失败原因。浏览器工具返回 request-header policy 加载错误，因此本轮未操作用户实时酒馆页面，真实酒馆联网 AI 完整流程尚未验收。

## 更新

在酒馆扩展管理中更新 Atlas，然后刷新页面。手动安装使用 `atlas-ui-extension-0.9.78.zip`；保留已有聊天与设置。
