# Atlas 0.9.78

修复原版 UI 与酒馆宿主的交互遗漏，保留原版 CSS、字体、配色与地图交互。

## 修复

- 从酒馆扩展菜单打开 Atlas 时，点击继续冒泡到酒馆的关闭处理，菜单不再残留在新工作台上。支持 Enter 和空格打开；关闭后再次打开恢复工作台键盘焦点。
- 「推演」页接回当前聊天的启用／暂停开关，保存至真实宿主绑定。停用聊天可重新启用；处理回合期间禁止切换。
- 「推演」页提供 API 连接、提示词、任务绑定和诊断的直接入口，显示当前聊天推演状态。
- 推演或初始化失败后保留错误原因；未建立世界时也能看到错误。初始化返回失败不再提示成功。切换聊天不携带上一个聊天的操作错误。
- 推演期间显示处理状态，阻止重复点击。没有活动聊天、SQL 开关关闭或聊天停用时给出状态。

## 后台入口

新工作台右上角滑杆按钮打开 API、提示词和任务预设；左侧「推演」页也能直接进入这些设置。左侧「诊断」可展开日志并导出。

「世界后台／主角所知」按钮切换信息视角。浏览器安装形态的引擎在酒馆页面中运行，SQL 世界数据随当前聊天保存；不要求额外运行 Atlas 服务器插件。

## 验证

- 类型检查、构建、打包通过。
- 完整测试 1612 项通过，其中原版接线针对性测试 31 项；总套件包含后端和历史兼容回归。
- Chrome 对实际安装目录的 54 项检查通过，无浏览器错误。新增菜单测试使用按 SillyTavern 官方菜单事件逻辑制作的隔离宿主；新增推演错误展示测试注入故障，未调用用户在线模型。
- 原版两份 CSS 和字体哈希保持一致。

本轮无法读取用户的实时浏览器页面：浏览器工具连续返回 request-header policy 加载错误。用户这次推演失败的具体原因仍需结合真实日志确认；停用状态是代码确认存在的一种失败条件，不能据此断言此次失败的唯一原因。真实酒馆联网 AI 完整流程尚未验收。

## 更新

在酒馆扩展管理中更新 Atlas，然后刷新页面。手动安装使用 `atlas-ui-extension-0.9.78.zip`；保留已有聊天与设置。
