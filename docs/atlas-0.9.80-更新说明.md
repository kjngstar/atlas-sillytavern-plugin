# Atlas 0.9.80

修复普通发送过程中嵌套内部生成时，Atlas 没有准备回合、没有推演回执的问题。

## 修复

- 生成门控由单个布尔值改为请求生命周期栈。内部 quiet／dryRun／automatic 请求结束后恢复尚在运行的正文请求；发送前进行内部预处理也不会锁住随后到来的用户楼层。
- 区分正文楼层收到、原始生成结束和命令执行后结束通知。内部请求的第二个结束通知不会结束它的父请求；重复完成通知不重复调用模型或保存世界。
- 内部请求停止时只结束内部请求，保留正文回合和临时注入；正文停止仍正常取消推演。
- 聊天尚无楼层时也处理内部结束通知，避免首楼发送前门控残留。
- 诊断新增安全的生成序号、类型、dryRun、automaticTrigger、quietPromptPresent 和完成信号，不记录原始请求参数或提示词正文。

## 验证

- 完整 1624 项测试与类型检查通过。
- 实际安装包、SQL 引擎与原版 UI 在隔离 Chrome 宿主中通过 28 项生成链路检查；新增发送前嵌套内部结束／停止、正文准备后内部停止的场景。
- 修改前复现两项失败，修改后通过。
- 原版 UI 的 59 项浏览器检查和 SQL 发布包检查通过；原版 CSS 与字体哈希一致。

隔离生成检查使用测试模型响应。真实酒馆验证的结果另行记录，不把隔离测试计为在线模型实测；具体 shujuku 配置的兼容情况需真实事件确认。

## 更新

在酒馆扩展管理中更新 Atlas 后刷新页面，核对版本为 0.9.80。手动安装使用 `atlas-ui-extension-0.9.80.zip`。普通发送完成后，在「推演」或底部「推演回执」查看结果和日志。
