# Atlas 0.9.83

## 空间布局接入

- 普通酒馆楼层在地点与人物建档后，使用新建地图的真实引用调用空间布局任务；模型提交房间、陈设或城市地块参数，程序生成几何并保存到同一聊天快照。
- 作者视图的当前地图提供「生成布局／更新布局」，用于补画已有存档；此任务不重演故事事件、不推进时间。
- 修复陈设所在房间引用未解析，以及布局请求和场景写入共用操作编号导致场景被误判重复的问题。
- 新实体创建失败时，拦截依赖它的人物、关系与事件，避免悬空外键导致整轮保存失败；纠错后按新的原子分组清除旧失败回执。
- 插件提供示意画布宽高，模型遗漏幅面字段时仍可组装有效的房间与陈设；修复地图信息卡内布局按钮无法接收点击的问题。
- 单独房间与无子房间的载具支持内部平面图，保留该地点在父地图上的坐标，不生成虚假的走廊；窄车厢支持陈设旋转及适配通行空间。
- 修复房间自引用造成 UI 循环读取失败；新快照先验证后替换，避免读取错误清空当前界面。
- 修复长椅未映射到原 UI 家具绘图类型、缺陈设旧图被误判成功复用，以及显式删除的重复陈设被几何层重新并回的问题。
- 手动布局使用独立请求编号，完整保存分组、问题及落库结果到「推演回执」。
- 无河流资料的城市支持多边形、道路与建筑；有河流约束时绘制河道。原 UI 配色、纹理与地图交互沿用提供的 UI。
- 小型布局任务输出预算最多 4096 tokens；原连接设置保留。模型超时或没有有效约束会明确报告，已保存的实体结果保留。

## 验证

- 自动楼层的集成测试覆盖房间、木柜、长椅、人物几何与重开读取，父地图位置保持一致。
- 测试覆盖无河城市的合法多边形、道路、建筑及空水域。
- 1645 项自动测试通过；TypeScript 类型检查与 SQL 发布包验证通过。
- localhost:8000 的实际聊天验收：从已有楼层提取实体，生成车厢、两张座椅、暗柜与人物；增量清理重复陈设后回执为 committed，issues 为空、coreSaved=true，时间保持 1800→1800。已保存布局可重开读取。
- 实测使用酒馆当前主连接；原 MiniMax 独立连接设置保留，其请求超时尚未获得成功验证。

## 边界

几何尺寸与排布为带依据的空间示意，不能视为测量结果。不会仅为了复刻样例而给没有水系资料的地点添加河流。
