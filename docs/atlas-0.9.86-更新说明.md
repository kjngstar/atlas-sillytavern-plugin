# Atlas v0.9.86

发布日期：2026-10-10。

本版整合 0.9.83 之后的世界建设、SQL 保存与回执修复，以及新 UI 空间细节、API 控制和脚本网关兼容改进。

## 更新

- 世界建设读取角色和世界资料，按预算分批补全地点与地图；事实、建设与空间布局各自校验，保存后刷新地图和回执。
- 已登记的室内空间生成房间轮廓、连通走廊、门窗、灯光与用途合理的陈设。庭院、花园有独立的室外表现；视野按实际布局范围适配。
- 保留原 ATLAS 参考页面的视觉和交互；移动载具进入移动图例；单间与车辆空间保留已保存的陈设和留场人物。
- 布局回复出现无法解析的 JSON 且没有有效操作时，在剩余请求预算内自动请求一次完整格式纠错，坏回复不会写入地图。
- 推演回执补齐模型请求阶段、HTTP 状态、耗时、输出字符数及纠错记录；失败/部分成功按实际结果显示。
- 恢复 API 页获取模型功能，保留可调整的请求超时设置。输出长度设为 0 时，ATLAS 不主动发送输出 token 限额；正数仍可指定限额，最终能力由提供商决定。
- 兼容现有酒馆脚本网关返回的普通正文和工具调用承载正文；不内置第三方网关。ATLAS 内部地图请求已在本机通过现有 MiniMax 和 Gemini 连接测试。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `atlas-ui-extension-0.9.86.zip` | 酒馆 ATLAS 扩展，日常安装或更新使用 |
| `atlas-server-plugin-0.9.86.zip` | 独立服务器插件组件 |
| `atlas-source-0.9.86.zip` | 本版本提交对应的完整仓库源码 |
| `atlas-0.9.86-SHA256SUMS.txt` | 上述三个压缩包的 SHA-256 校验值 |

更新扩展前关闭工作台，将扩展包内文件覆盖到原 ATLAS 扩展目录，然后刷新酒馆。扩展包自带运行产物，无需在安装目录构建。聊天存档不包含在安装包中。

## 验证与范围

- 类型检查、构建与自包含打包通过；本版串行全量测试 **1,857/1,857 通过，0 失败、0 跳过**，避免发布目录扫描与打包并发。
- 本机真实酒馆的住所测试生成 6 个空间、12 组陈设和 6 个入口，经过一次格式纠错后成功提交 2 组、失败 0 组；刷新后布局及日志恢复。
- 空间图是依据资料生成的估计示意，不是建筑测绘。未登记的楼层不会自动当作已还原；世界内容按预算逐批建设，一次批次成功不代表全世界完成。
- 模型返回仍可能出现格式或引用错误；一次纠错之后若仍不合格，保留已有世界并显示失败。测试覆盖本机 Windows/Chrome 和既有连接，不宣称多平台或长时间压力验收。
