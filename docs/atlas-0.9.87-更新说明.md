# Atlas v0.9.87

发布日期：2026-10-11。

本版整合 0.9.86 之后的地图与布局同步生成、地图分析导出、酒馆生成共存和世界书读取控制修复。

## 更新

- 本轮已登记的缺失或结构变化地图统一排队组装空间布局，按批完成后保存。空间组装使用独立的有限请求预算，不再因前景任务耗尽共享预算而留到进入子图才补画；打开地图只读取已保存内容。
- 修复观察和世界建设阶段重复登记同一父地点下的同名房间。远处已登记的地点也参与去重；不同父地点的同名房间保持独立，已有歧义不擅自合并。
- 修复新空间幅面的小数格数和尺寸别名不一致，保留物理纵横比。删除室内图的宽度文字与尺寸辅助线。
- 地图右侧新增导出按钮，可下载或复制当前图及其子图的 JSON。选择世界图可导出当前视角下的完整地图层级；文件包含父子关系、布局约束、生成几何、尺度与画布投影，供其他 AI 分析。
- 世界书条目新增独立的 ATLAS 读取控制：保持酒馆条目启用，也可单独让 ATLAS 忽略该条目。
- 修复宿主流式正文提取、空回复分类、完整世界书输入和聊天尾部上下文注入，强化地图与世界建设默认提示词。
- 修复酒馆 dryRun 收尾，以及 shujuku 在正文完成后追加自身投影块导致的误判；真实正文编辑和换 swipe 的候选过期校验仍生效。已确认保存的回执如实显示保存结果。
- 保留现有脚本网关兼容、模型列表获取、请求超时设置，以及输出长度设为 0 时不主动发送输出 token 限额的行为。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `atlas-ui-extension-0.9.87.zip` | 酒馆 ATLAS 扩展，日常安装或更新使用 |
| `atlas-server-plugin-0.9.87.zip` | 服务器插件组件 |
| `atlas-source-0.9.87.zip` | 本版本提交对应的完整仓库源码 |
| `atlas-0.9.87-SHA256SUMS.txt` | 三个压缩包的 SHA-256 校验值 |

关闭工作台，将扩展包内文件覆盖到原 ATLAS 扩展目录，再刷新酒馆。安装包包含运行产物，无需在安装目录构建，不包含聊天存档和 API 密钥。

## 验证与范围

- 类型检查通过；串行全量回归 **1,897/1,897 通过，0 失败、0 跳过**；构建与打包通过，最终产物发布审计 **11/11 通过**。
- 本机普通酒馆发送实测：主角留在大厅，未进入的附楼、四间房和中央走廊均在同轮完成布局并保存；建设阶段复用四间房，未新增重复记录。地图 JSON 的实际下载和复制均成功。
