# Atlas 0.9.89-rc.1

基于用户指定的 0.9.88 hotfix，发布两阶段地图修复测试版。为兼容现有数字版本工具，manifest 和组件版本统一为 0.9.89，安装包与补丁元数据标记 rc.1。

## 改动

- 第一步通过原文片段编号提取空间依据，由程序还原文本；跨块保留上下文，单图摘录错误独立处理。
- 第二步逐图排版，拒绝 length 截断响应，保留旧场景；无效实体引用可定向纠错一次。
- 修复新建父子图尺寸不一致、未标定画布扩容失败及已有子空间被缩小的问题。
- 地点与路线临时编号分离，使用本图合法 JSON 示例，并恢复布局失败的界面重试入口。

## 验证与边界

功能代码完整测试 2133/2133 通过，类型检查通过；版本同步后 127 项发布检查通过。真实酒馆最终一轮中，9/9 已登记地图均生成场景，场景问题为空，数据库完整性和外键检查通过。

完整回合仍为 partial：上游建档/建设存在非法枚举、地点 JSON 和路线字段层级错误，失败项保留重试。这是测试版，尚未通过完整世界建设全部 committed 的稳定版门槛。

远程验收安装包及说明见 [GitHub 预发布页](https://github.com/kjngstar/atlas-sillytavern-plugin/releases/tag/v0.9.89-rc.1)。
