# Atlas 0.9.90-rc.1 测试版

发布日期：2026-10-17。基于 `v0.9.89-rc.1`，合入 0.9.90 修复包及本机后续修复，供其他 AI 独立验收。GitHub 标记为 Pre-release。

## 修复

- 接通人物联系线：选中人物后按当前地图读取关系，新增显示开关，显示关系名称。
- 接通已保存传播任务的路线；修正读取路由丢失选中对象参数、缺少地图参数和到达风声源地点解析的问题。
- 传播光点使用已提交进度，不因浏览器动画播放自动推进世界；缺少几何和跨图坐标不补假线。
- 保护切聊天、切图、切视角的异步结果；主角所知不沿用作者后台的路径。
- 修正闭合轮廓的起点和曲线邻点索引，消除顶部翻折、重叠尖边和直线接缝；开放曲线保留全部端点。
- 修正布局成功误报：支持界面地点标识解析，并识别本轮真实生成但内容未改变的场景日志；失败时不能用旧场景充当本轮成功。
- 合入世界书桥接、独立读取控制、逻辑地图归属、只读展示代理、完整游标分页、路线端点预检、旧约束清理等 0.9.90 修复。
- 保留 0.9.89-rc.1 的资料摘录→逐图布局流程、截断保护及有限重试。

## 验证范围

- 当前功能代码完整测试 **2194/2194**，0 失败、0 跳过；类型检查、打包通过。
- Codex 内置浏览器：独立合成 SQL 存档经过实际读取路由与完整生产界面，验证联系线开关、消息入口、40% 已提交传播进度和视角隔离。
- 真实酒馆已有世界：世界书 120 项、地图层级、缩放与一次真实单图布局完成；原生回执 `committed`、`coreSaved=true`、`sceneSaved=true`。
- 原有验收聊天没有关系、信息或传播任务记录；联系与传播线采用独立 SQL 存档验证，未声称已在该聊天从新剧情自动创建出来。
