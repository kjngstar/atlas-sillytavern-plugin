# Atlas 0.9.91-rc.1 修复测试版

日期：2026-10-18（北京时间）。基于 `v0.9.90-rc.1` / `761c7ceabfa3e2c1851cdcc87a26e8d012fa27c9`。
数字 manifest/package/health 版本为 `0.9.91`，补丁元数据标识为 `0.9.91-rc.1`，数据库 schemaVersion=3。

## 本次修复

1. 双向路线的返程行程会反转折线；单向路线不会显示非法返程。
2. 缺失、损坏、方向错误、不连续的行程几何不会被拼成虚构捷径。跨图行程只显示本图连续部分；人物已经离开本图时，不在本图伪造当前位置。
3. 人物行程光点按当前路段与该路段已提交进度定位，避免把整段耗时百分比直接当作折线距离百分比。初始快照与地图切换使用同一投影函数。
4. 主角视角的在途消息、已到达风声与消息目录统一检查实际认知。只知道某地点，不代表知道当地所有消息；未来才收到、尚未发布或已经失效的信息不会解锁传播路径。
5. 粗定位人物的关系线可连接本图已有的人物展示标记，并标注“示意”。展示点不写回 SQL；缺一端标记时不补点，跨图关系不补连线。
6. 正文观察提示词明确说明何时保存人物关系，如何使用公开风声地点与明确接收者；保留不将闲聊自动建成传言、不将秘密公开的约束。
7. 修正 SQL 发布验收脚本中的旧模型夹具，使其分别返回有效的证据摘录和布局约束；新增实际发布界面的联系与传播浏览器验收脚本。

## 验证方法

- 原版标签的自动测试独立重跑：2194/2194，0 失败、0 跳过。
- 新增真实 SQL 回归覆盖：反向行程、缺段、非法返程、路段速度差异、跨图光点、未获知风声、未来/过期消息、粗定位关系线，以及关系与消息的生产提交和保存。
- 类型检查、打包、完整自动测试和浏览器检查的最终结果见同包 `验收报告.txt` 与 JSON 证据。
- 完整测试在资源受限环境可运行：`node --test --test-concurrency=2 --no-warnings=ExperimentalWarning --experimental-strip-types "tests/*.test.mjs"`。
- 发布产物检查：`node tools/verify-sql-release.mjs`。
- 生产界面检查：`node tools/verify-reference-browser.mjs`。
- 酒馆事件检查：`node tools/verify-host-generation.mjs`。
- 联系与传播检查：`node tools/verify-contact-flow-browser.mjs`。
- 浏览器工具支持 `ATLAS_CHROME_PATH` 指定 Chrome 路径；新联系传播工具默认也可使用 Playwright 安装的 Chromium。

上述浏览器测试使用隔离宿主、真实发布代码与 SQL/WASM；模型返回由可重复夹具提供。它们证明接口、事件、持久化和界面接线，不等同于已经在用户本机酒馆中调用外部模型。完整世界自动建设及不同模型输出质量仍需要实际使用观察。

## 安装

解压交付包，将 `atlas-ui-extension/` 内的文件覆盖到当前 Atlas 扩展目录，随后在浏览器按 Ctrl+F5 刷新。
覆盖目标是现有扩展目录；不要在它里面再套一层 `atlas-ui-extension`，也不要同时保留两份可加载的 Atlas 扩展。
普通浏览器 SQL 模式使用界面组件即可；保留原聊天数据继续读取。

本次检查时远端 `main` 仍为 0.9.88；测试版位于独立发布分支。应根据实际安装来源更新，避免旧分支再次覆盖手动安装的修复版。
