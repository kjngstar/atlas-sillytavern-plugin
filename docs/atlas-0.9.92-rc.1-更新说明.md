# Atlas 0.9.92-rc.1 地图修复测试版

日期：2026-10-18。基于 main 的 0.9.91-rc.1（`d19e4319cb45521920d4f4ec8d998354606540ec`）。
manifest/package/health 版本为 `0.9.92`，补丁标识为 `0.9.92-rc.1`，数据库 schemaVersion 保持 3。

## 本次修复

- 观察、建设、后台结算、资料摘录、排版、连接兼容重发共用每次操作最多 4 次实际模型请求的预算。地图数量不再放大预算。
- 自动排版按当前有人所在地点的祖先链，由上至下处理；远方未访问的内部图保留登记，可手动选择后生成。共享父子室内细节仍可由程序本地同步。
- 长资料优先选择与所选地图有关的一批片段做证据摘录，为排版留出额度；未读取的资料会明确报告，不当作已验证事实。
- 概览排位按区域所需半径预留空间，避免大城市因邻居太近被单独缩成小块。确认轮廓和物理尺寸仍优先于 small/medium/large 的估计。
- `road_texture` 限制在已登记区域内。旧存档中没有区域边界的随机长曲线不再绘制。真实通行路线仍须登记两个地点端点。
- 旧存档中名称明确为“两座已知城市之间道路”、且两端唯一可见的道路区域，在界面改为城市边界之间的连接示意；不会自动写入可通行路线、距离或旅程。
- 载具内部图保留；外部停靠或粗位置可显示载具入口，并标注位置未知。已登记行程继续使用真实路线和已提交进度，不另造一个移动光点。拒绝新写入的自身停靠锚点。
- 子图显示父图中该地点的实际轮廓，并保留可见同级区域的相对方位与可点击入口。街区不再将父图多边形平滑成相同圆角方块；内容限于继承边界内。
- 父图多边形足迹参与子空间尺寸解析，明确区分米和格；缺少米/格标定时不伪造物理尺寸。排版请求同时携带可用的父图轮廓及同级区域上下文。
- 默认地理提示词补充道路、载具、重复地图标题层级、城市尺度依据和父子图继承规则。

## 旧聊天如何使用

更新扩展并 Ctrl+F5 刷新。随机旧曲线的隐藏、旧道路连接示意、载具入口和父子图上下文在重新读取地图时生效，不需要清空聊天。

旧存档中的面积错误属于已保存的估计几何。选中相关上级地图，点击“更新布局”，才能用新算法保存新的轮廓；布局策略指纹已更新为 `layout-v7`。失败时保留原场景。

更新不会把旧道路示意自动确认为真实路线，也不会凭空补齐未登记的出发时间、速度、轨迹或邻接事实。不同自定义提示词和模型输出仍可能需要人工纠偏。

## 验证

自动测试覆盖真实 SQL 请求预算、长资料后仍完成排版、自动选图顺序、面积相对顺序、纹理边界、载具外部入口、父子轮廓、同级导航和单位换算。最终结果记录在组件的 `ATLAS-PATCH-INFO.json`。

浏览器检查使用实际发布代码与 SQL/WASM，宿主和模型由可重复夹具提供。额外工具可只读回放本地地图分析导出：

```bash
node tools/verify-map-hierarchy-browser.mjs /path/to/map-analysis.json
```

加 `--rebuild-overview` 可在内存里用原约束重算概览，检查旧面积修复效果；它不导入、不修改聊天存档，不调用外部模型。导出文件和截图不进入公共仓库。

此测试版未在用户本机酒馆内调用外部模型实测。
