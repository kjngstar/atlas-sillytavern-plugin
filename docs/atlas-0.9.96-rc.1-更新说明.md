# Atlas 0.9.96-rc.1 建图修复预发布版

日期：2026-10-20。组件版本 `0.9.96`，数据库 schemaVersion 保持 3。

**这是预发布版，实机验收尚未全部通过。** 最终代码已通过自动回归，但最新一次 MiniMax-M3.1 整轮实测首个请求等待 300000 毫秒后超时，未进入建图阶段。此前 M3 构建曾完成空白聊天建图、保存及刷新恢复；这不能代替最新代码的 M3.1 整轮验证。

## 本次修复

- 房间已知长宽可以独立保存，不再为尺寸编造父图坐标。确认尺寸在父图、房间子图和空间账本之间保持一致。
- 建设阶段删除受保护字段后不再提交空更新；相同事实按无变化处理，有效无变化在宿主保存确认后推进来源进度。
- 自动纠错复用本轮已经创建的人物，避免将定位修复保存成同名 NPC。
- 布局重试继续携带失败请求中的既有约束、稳定陈设 ID 和错误原因，减少重复家具；调整家具摆放次序和室内可用空间。
- 建筑内包含房间的中间容器按结构关系选择室内模板；首次、未标定且未锁定的估计幅面为子空间预留容量。作者确认、锁定及已保存的尺寸继续受保护。
- 父图建立楼层尺寸时，不再提前把多房间楼层保存为单间或标记完成。
- 首次规划的矩形物理尺寸参与生成前标定，避免与旧正方形格框产生比例冲突。
- 修复主题导致的工作台高度为零、窄窗口关闭按钮隐藏，以及室外上下文挤压室内视野的问题。

## 请求与版本

沿用 0.9.95 的“按同类工作分批”：地图、人物、空间证据和事件结果默认各 1 批。地图生成默认共享证据提取 1 次、统一规划 1 次；完整空白世界通常还包含观察及建设请求，不等于整轮只调用一次 API。没有增加默认请求次数。

布局策略更新为 `layout-v9`。已有布局可能因策略变化需要更新；普通人物移动仍不应触发结构重画。

## 验证范围与限制

- 发布前重新运行全量自动测试、类型检查、构建和打包卫生审计；准确结果随组件 `ATLAS-PATCH-INFO.json` 发布。
- 本次开发阶段 264 项针对性回归通过，覆盖确认尺寸、真实 SQLite 候选提交、来源保存确认、纠错身份、嵌套楼层、首次幅面标定等。
- 早期 M3 实测：空白聊天一次触发，4 次请求、无重试；保存村图、旅舍、大厅及厨房，刷新恢复成功。
- M3.1 补测发现的中间容器分类、楼层提前完成、首次幅面标定问题已增加回归并修复；最终版本的实机复测因首请求超时未完成。**不能宣称完全验收通过或连接问题已解决。**
- 自动布局覆盖当前人物所在活动分支及相关父图，不代表世界所有已登记节点都有独立场景。
- 正文缺少可结算耗时依据时，回执可能保留 `TIME_UNRESOLVED` 并显示部分成功，时钟不会被虚构推进。

## 安装与更新

- 已从本仓库安装的酒馆扩展：在扩展管理中拉取 `main` 的更新，然后刷新页面。
- 手动安装使用 `atlas-ui-extension-0.9.96-rc.1.zip`；服务器插件单独使用 `atlas-server-plugin-0.9.96-rc.1.zip`。
- `atlas-source-0.9.96-rc.1.zip` 为源码包；`atlas-0.9.96-rc.1-SHA256SUMS.txt` 提供附件校验值。
- 本版不更改用户连接、API 密钥或聊天数据。需要稳定版的用户可继续使用已有稳定发布。
