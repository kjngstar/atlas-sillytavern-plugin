# Atlas 0.9.96-rc.2 日志增强与地点概况收纳

日期：2026-10-21。组件版本沿用 `0.9.96`，数据库 schemaVersion 保持 3。

本 tag 包含已合并的 PR #4 和地点概况伸缩栏，继续作为预发布版。

## 改动

- 地图左上角的地点概况默认收起为一行，点击标题或箭头展开；支持键盘 Enter、空格切换。人物、物品、消息统计及布局按钮收纳在展开区内，数据刷新不会强制展开。
- PR #4：真实模型发送、响应头、响应体和最终结果带独立请求指纹、阶段及回合关联；记录输入规模、超时参数、兼容重发和真实发送次数。
- 请求失败保留底层错误，地图问题逐项记录字段路径，保存确认与布局完成分别报告。构建标识、脱敏和日志增量刷新同步增强。

## 验证与限制

- 伸缩栏改动后，36 项相关回归、类型检查、打包及 99 项工作台浏览器检查通过，浏览器错误 0 项。
- PR #4 合并版本此前全量 2303 项自动测试通过；本 tag 发布前重新执行完整测试。
- Codex 内置浏览器访问真实酒馆与已有 MiniMax API：M3.1 首次请求返回 HTTP 200 错误 JSON，记录 RESPONSE_MALFORMED，未提交世界变化。
