# Atlas 0.9.97

发布日期：2026-10-26。本版本包含 PR #8 的地图空间展示修复与逐轮调用分析导出，插件、组件入口、服务端 health 和安装包版本统一更新为 `0.9.97`。

## 地图展示

- 建筑内按真实空间类型展示楼层、房间与室外入口。楼层通过选择器进入；没有楼层依据的房间保留原归属，并明确显示“楼层未标明”。
- 含储物间等子房间的主房间保留自己的可用地面、家具、人物和物品。已有尺寸、陈设身份与锁定结构继续生效。
- 城市地图展示已登记建筑与保存的示意道路，移除额外生成的随机街块；局部地图取景不再被远处同级地点撑大。
- 地图导航补充“位置待完善”和“内部待布局”提示。浏览、切楼层与展开导航均不调用模型。

## 逐轮调用分析

在作者视角打开「诊断 → 导出逐轮分析」，下载 `atlas-turn-analysis-*.json`。原有日志导出入口保留。

分析文件汇总所有已保存回合的状态、实际变更、问题及可用的模型发送记录，区分正常任务、补交、格式修复、网络重试、兼容重发与后台继续。新回合保留最近 256 次发送明细及完整累计计数；会话历史另保留最近 1000 条模型与回合事件。

文件仅导出经过过滤的计数、指纹和允许的元数据，不包含密钥、连接地址、完整提示词或模型回复。旧记录缺失的明细、被淘汰的历史或无法确定是否重叠的计数，明确显示缺失或未知。

## 更新与版本回溯

在酒馆扩展管理中确认 Atlas 跟踪 `main`，更新扩展后刷新页面，版本应显示 `0.9.97`。手动安装须使用完整安装单元，保留 `ui/`、`dist/`、脚本、样式与 manifest。版本 tag 为 `v0.9.97`。

世界数据继续随聊天保存。本次没有调整用户请求额度，也未新增地图生成的模型阶段。显示修复可读取旧场景生效；生成器与空间账本修复需要更新受影响图的布局。缺少布局的地图不会自动补造，地图分析 JSON 也不能作为世界存档导入。

详细行为见[地图修复说明](map-spaces-repair-20261024.md)与[逐轮分析说明](map-quality-and-turn-analysis-20261025.md)。其中开源组件与空间规划契约属于研究提案，尚未接入本版本。
