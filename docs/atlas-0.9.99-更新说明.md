# Atlas 0.9.99

发布日期：2026-10-28（Asia/Shanghai）。本版本包含 0.9.97 之后尚未发布的世界建设与空间行为实现，以及建设重试、功能分区和逐轮分析修复。

## 插件变化

- 世界建设使用 SQL 持久任务、目标与窗口账本，区分来源扫描、地点登记和实际布局。失败目标可单独重试；停止、过期回执、回退及再次继续沿用原保存 ACK 和分支规则。
- 地点、路线及来源目录使用统一操作额度与稳定引用；分层建设保留已完成目标，按依赖执行，补全不会把缺少尺寸的空间当成已确认的物理尺度。
- 玩家地图、正文与后台读取按可见范围和知识作用域过滤。人物初始位置、道路旅行、场景进入、空间矛盾及陈设转为真实物品接入 SQL 变更链路。
- 室内开放功能区保存为父房间内的独立区域，保留原地点 ID 和类型；新建布局和旧场景重试使用同一投影，不会生成隔墙或搬动原家具。缺少确认边界时标记为估计，尺寸无法容纳时明确报错。
- 建设完成判定同时检查实际覆盖、几何、通路和合理性；容量计算、结构指纹及陈设保留的修复接入真实布局入口。
- 工作台区分业务轮、后台窗口与管理操作；逐轮分析汇总已存储发送账本。旧轮次缺失明细时继续显示未知值和可证明下界，不补造精确总数。

用户已保存的自定义预设、请求上限与 API 绑定沿用原设置。没有新增建设队列，没有改写用户角色卡、世界书或聊天正文。地图皮肤、字体、CSS 和绘图框架保持原样。

## 更新

在酒馆扩展管理中更新跟踪 `main` 的 Atlas，刷新页面后核对版本 `0.9.99`。手动安装使用完整的 `atlas-ui-extension-0.9.99.zip`；使用可选服务端插件时同时更新 `atlas-server-plugin-0.9.99.zip`。发布附源码压缩包和 SHA-256 校验清单。

已有世界仍随聊天保存。涉及结构已变化的地图继续走正常布局；符合既有结构的房间可通过原「集中重试失败项」入口补齐功能区。估计范围不会升级为作者确认事实。

- 版本升级前的完整回归：3016/3016 通过，0 失败、0 跳过；13 项构建、SQL/WASM、工作台、地图及用户地图只读回放门禁通过。版本升级后将重新执行同一组发布门禁，结果在发布记录中列出。
