该兼容检查不是完整的预设迁移；现有旧预设仍需要后续兼容草稿/选择接线。

`runSqlTurn` 对并发/重复楼层事件共享请求，已确认回合直接返回 duplicate。

不二次推进时间、不修改业务 head/revision，并更新回执与世界书同步意图。
