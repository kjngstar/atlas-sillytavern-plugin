## 发现并修复

从教学楼进入教室再返回时，教学楼原先的缩放从约 156% 重置为 100%。
定位原因：视口尺寸监听会清空所有地图的相机缓存；面包屑、状态说明或屏幕宽度变化均可能触发。

修复：按地图记录其视口尺寸。尺寸变化时重新计算当前图的适配基准，保留地图中心和相对缩放，不清空其他地图视角。聊天和分支切换仍正常清理作用域缓存。

修复代码提交：`e78ede2`。插件显示版本仍为 0.9.73 测试修订，本次未推送新的 GitHub main 版本。
