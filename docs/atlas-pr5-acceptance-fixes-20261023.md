# PR5 验收问题修复与遗留 UI 归档

日期：2026-10-23。基线：`bb91fd0`，主插件版本仍为 `0.9.96`。本轮更新同一个草稿 PR #5，供本地酒馆复验。

## 行为修复

1. **房间连接**：保留两房间原有稳定布局；为分叉、上下共墙和锁定房间补充四向矩形搜索与成对门洞。尺寸与确认位置保持为约束，真正绑定的走廊仍保留接触关系；没有走廊需求的直接连接图不再强塞中央走廊。局部搜索有计算预算，达到预算单独报告 `ROOM_TOPOLOGY_SEARCH_LIMIT` 并保留旧场景，不宣称数学上无解。普通大厅三向连接和父子图上下入口已有回归。
2. **顺序时间**：观察阶段提示明确要求用事件 `ref` 表达先后或同时；SQL 结算传递事件别名、操作 ID 和实际事件 ID。过滤、前向引用及重复通知不再依赖临时数组位置。60 秒步行后交谈 120 秒结算 180 秒，同时则取 120 秒。无法解析、重复或循环的引用用 `TIME_RELATION_CONFLICT` 报告，保守结果标为估计。
3. **书桌尺寸**：普通 desk 的实际 body 与 group 尺寸一致，不再乘以 0.68，也不隐式附赠椅子。小房间在首轮摆放失败时尝试靠墙候选，保留完整占地并检查门口、交互点和通路。
4. **回执诊断**：通用 API、地图操作和正文提交统一保留 `outcome: partial`。数据已保存的部分回合显示 `COMMIT_PARTIAL`；未确认保存的候选仍报告失败，具体问题继续单独记录。
5. **旧几何刷新**：布局策略升为 `layout-v14`，布局请求指纹包含策略；室内生成细节策略为 `four-way-full-size-furniture-v3`。下一次布局会重新计算旧策略结果，避免命中旧缩小桌体缓存。已有历史时间记录不会因加载新版而自行重算。

## 代码归档

- 11 个旧工作台模块（2,109 行、98,192 字节的原始源码）迁入 `tests/fixtures/legacy-ui/modules/`，正式 UI、镜像和安装包不再携带这些模块。
- 旧 CSS 皮肤与地图令牌实现迁到 `tests/fixtures/legacy-ui/skin.mjs`；旧面板的标签、缓存、样式加载器和上下文函数迁到 `panel-support.js.txt`。当前入口只保留新皮肤运行时。
- 历史测试入口改名为 `readLegacyUiSource`，避免将拼接旧面板的测试说成当前界面验收。旧行为断言保留。
- 删除当前地图未调用的 `drawGhosts`、皮肤包未使用的 `own` 和生产入口无效导入。
- UI 同步会清掉源目录已退休的文件，防止增量构建把旧组件留在镜像或发布包。
- HTML 的 `atlas-boot-scripts` 成为运行时与引用审计共同读取的清单；审计补上 HTML 入口及 vendor 依赖，不再误标正在运行的皮肤模块。

旧档迁移、旧引擎回归、类型声明、旧浏览器导出和旧 CSS 仍有明确兼容或测试边界。本轮未将整个 lib/src 或样式表当成垃圾批量删除，也没有引入新的运行依赖、渲染框架或模型请求阶段。
