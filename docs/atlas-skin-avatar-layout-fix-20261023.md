# 皮肤头像与切换偏移修复

用户截图指出：圆角头像被套上方形边框、头像仍是默认蓝紫渐变，切换皮肤时界面发生位移。

## 原因与修复

- 旧窗框通过真实 `border` 占用内容区。「晴空信笺」导入后地图向右、向下各移 18 CSS 像素，画布宽高各少 36 像素，尺寸观察器又按新视口重算相机缩放。窗框现改在独立、不接收点击的装饰层绘制；面板框也不再增加实际边宽。
- `border-image` 不随 `border-radius` 裁成圆角，原来又把同一个窗框用于头像、小导航按钮。两包移除了额外改变地图树留白的密度参数。小图标改用皮肤颜色与圆角的单层细边框；文字按钮的图片装饰按自身圆角裁切。
- 头像只换了外框，基础 `background-image` 里的蓝紫渐变没有被 `background-color` 覆盖。现在人物卡、详情和作者/主角视图标识统一替换内芯配色、状态点和边框，保留人物首字与状态含义。
- 晴空信笺 1.0.1 新增独立云蓝圆形头像框；山河志 1.1.1 新增独立青玉圆形头像框。两张素材由内置图像生成制作，保留真实透明通道。旧包若把窗框同时指定给头像，会回退为无方框的主题文字标识；重新导入新版同 ID 包即可安装专用头像框。

## 验证方式

先在旧构建运行新增浏览器检查，31 项中 11 项失败，实际捕获导入位移、头像残留渐变与九组换肤几何变化。修复后检查导入与切换前后的窗口、画布、导航、头像、地图树矩形和相机 x/y/缩放；三种显示配置分别在 360/720/1440 宽度下验证，误差阈值为 0.01 CSS 像素。

检查还覆盖实际 ZIP 文件导入、资源去重、图标命中、导出、10 次往返切换、旧包回退、刷新恢复、移除与世界数据不变。布局检查对真实浏览器取值，未用字符串匹配替代像素几何验收。全量自动测试 2410/2410、类型检查与打包通过；通用皮肤浏览器 55 项、当前界面浏览器 105 项通过。两套新包各 32 项专项通过，几何实测差值为 0，包含旧包回退。
