# 皮肤底色覆盖整个地图视口

## 缺陷与修复

旧渲染器在世界坐标下，用地图 extent 加固定 200 单位的边距填充背景。地图每帧先清空 Canvas；缩小或平移到这个矩形之外时，透明像素露出视口固定的深色 CSS 底，浅色图片皮肤出现深色带。窗框尺寸和相机不变无法检出此问题。

`ui/atlas-reference/js/map.js` 现在把自定义底色、纸纹和装饰背景作为视口层：保存绘制状态，恢复 DPR 屏幕变换，覆盖整幅画布，再恢复世界变换绘制地图。填色尺寸向上覆盖到完整物理像素，避免分数 CSS 宽高在 DPR 换算后留下半透明边缘。装饰背景按视口裁切，不随相机缩成一块矩形。

没有自定义底色、纹理或装饰背景的原始深色外观保持原绘制路径。地形、房间、尺度、实体位置、相机、命中及 SQL 数据均不由背景层修改；没有修改原始受保护样式，也不需要重新生成地图或导入皮肤包。

## 回归依据

新增的浏览器检查先在未修复的 PR #5 渲染器上运行，24 组尺寸/DPR/配置/地图类型组合全部检出了透明边缘；测试使用的发布版 `map.js` 与 `9bdb5ab5` 的文件哈希相同。

`tools/verify-map-backdrop.mjs` 已接入两套实际 ZIP 的正式文件导入验收：

- 晴空信笺 1.0.1、山河志 1.1.1，DPR 1/2、360/1440px、完整/地图优先/仅地图。
- 当前概览与通过正式空间生成器及投影器生成的大厅，适应视野、连续缩小三次、向左右远距离平移。
- 直接读取 Canvas 四条边，要求所有边缘像素不透明，四角保持浅色；远距离平移前后的角落纹样一致，检查装饰层没有随相机漂移。
- 保留已有几何、相机、命中、导出、刷新恢复、旧包回退与资源释放检查，另断言世界数据不变。
- 单元回归核对分数像素覆盖、绘制变换恢复、可选背景资源，以及原始深色分支。

每套皮肤包含原 32 项及新增 49 项，共 81 项浏览器检查。验收仍使用隔离 SQL 宿主与真实打包扩展；没有访问用户的酒馆存档或调用外部模型。
