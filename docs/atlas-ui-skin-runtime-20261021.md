# Atlas UI 系统与皮肤系统：实现和验收

日期：2026-10-21。基线：`v0.9.96-rc.2`（`7494ed6`）。开发分支：`codex/ui-profiles-skin-runtime-rc2`。manifest 保持 `0.9.96`。

## 实现

主目标为共用 UI 底座与可安装的完整皮肤。完整、地图专注、纯地图仅是可继承显示配置的三个实例；不构成独立前端、AI、数据库或地图引擎。

| 层 | 实现与职责 |
|---|---|
| 共用 UI Runtime | 现有 `app.js` 和宿主桥；保留页面、导航、选择、草稿、相机及业务动作 |
| 显示配置 | `ui-model.js` 白名单与继承；Slot 显示、有效页面，独立于手动折叠和作者/主角视角 |
| 外观控制器 | `atlas-appearance-controller.mjs`；准备、提交、保存、安装、导出、移除及异步竞态 |
| 外观设置 | `atlas-appearance-settings.mjs` 纯渲染，继续使用原有事件委托 |
| Skin Contract | `skin-runtime.js`；typed token、组件/笔触注册、迁移、CSS/Canvas 回滚 |
| Canvas Adapter | 原 `map.js` 的既有路径；保留几何、坐标、命中、标定与质量区分 |
| 数据包 | `atlas-skin-pack.mjs`；manifest、ZIP 结构、路径、实际解压量、CRC、图片头校验 |
| 图片准备 | `atlas-skin-assets.mjs`；串行解码、角色共享、取消与释放 |
| 宿主资源库 | `atlas-skin-storage.mjs`；IndexedDB、用户标识隔离、目录、配额与原子替换 |

框体、面板、按钮、图标边框、字体、圆角、间距、图例及地图笔触可独立改变。外部包仅提供数据与静态 PNG/WebP，不提供任意 JS、HTML、CSS、字体或远程资源。JSZip 3.10.1 使用 MIT 许可，按需加载。

未修改 AI 请求、提示词、世界协议或 SQL 表结构；没有引入前端框架，也没有替换地图引擎。

## 状态与恢复

- 关闭宿主、隐藏浏览器、有效页面非地图和销毁统一暂停；关闭后的快照与导航不会重新启动 RAF。
- 显示配置保留逻辑页面、输入 DOM、草稿、光标、滚动及手动面板折叠；不覆盖知识过滤。
- 纯地图标点点击复用现有详情渲染，在轻量浮层反馈，并可展开完整详情。
- 旧交互偏好保留单击进入与图例选项，迁移为 v2；保存失败保留本次选择。
- 布局失败恢复上一配置；迟到的外观准备和偏好保存不会冒充最新选择。
- CSS 与 Canvas 同步应用，失败回滚；旧图片在成功提交前保持可用。
- 导入前实际解码所有图片；解码失败不覆盖同名已安装包。存储失败保留可导出的本次预览，不保存不可恢复的图片启动引用。
- 删除活动包时先保存默认外观；保存失败不删除资源。
- 皮肤、交互和提示词草稿的宿主写入串行合并；跨聊天清理选择、搜索和相机缓存。

浏览器为 Chromium 133.0.6943.0，单进程、关闭 GPU 的受限环境。不能将这里的绝对帧率等同于桌面酒馆表现。

原生门禁包括既有 99 项和概览、城区、楼层的 6 项皮肤检查：笔触改变像素，保留几何、标点和相机。皮肤检查覆盖 3 配置×2 主题，360/540/720/1280/1920 px、DPR 1/2，100 次连续切换，真实图片解码、九宫格边框、标点点击、ZIP 导出、重启恢复、移除回退和资源回收。

100 次切换前后监听器为 14、ResizeObserver 为 1、Canvas 为 2，稳定态只有 1 个地图 RAF；关闭后仍为 0 RAF。切换未改变世界数据库，也未调用推演、布局、建设或回退等业务入口。图片验收中四种角色共享一张图片，稳定态仅保留 1 个 Blob URL 和 1 个 Bitmap，移除后归零。

纸面主题的中文回退、人物姓名、地点标题、选中控件和状态文字经过截图检查及文字对比度复验。纸面仍标记预览；图片验收素材仅用于证明安装链路，不作为官方美术皮肤发布。

地图实验中的旧 `.aw-*` 工作台测试已迁移到当前安装产物的原生门禁；保留原有 Leaflet 层级、网格、拥挤标点和响应式检查，不继续使用退役 DOM 与 Blob 模块入口。

## 默认外观与性能

同一演示世界、相机、1600×1000 视口与默认星幕，rc.2 和当前地图 PNG **逐像素一致**。SHA-256：`ee77191472b92445791b5dbec23c0a33536bff848c233c0fd563e64d1f1f430f`。为消除动画时序差异，两者均固定相机、暂停动画与雷达后比较。

| 60 秒采样 | rc.2 | 当前 |
|---|---:|---:|
| 帧间隔中位数 | 216.6 ms | 216.6 ms |
| 帧间隔 P95 | 266.6 ms | 266.6 ms |

帧间隔中位数变化 0%，每帧任务耗时增加约 4.50%，在本次 10% 相对预算内。受限软件渲染环境的绝对帧率较低，不作真实桌面性能承诺。样本内堆大小与启动时间保留在原始 JSON 中，不据单次样本声称改善。

UI 路径首次加载的未压缩响应体合计为 637,569 B → 697,393 B，增加 59,824 B；不是整个酒馆或插件的启动体积。两者默认启动均未请求 JSZip。


## 证据与复现

验收截图与原始测试记录随本地交付包提供；本 PR 提交源码、测试脚本、制作说明与验收结果摘要。


截图和模型失败用例使用隔离的演示夹具，不包含真实用户聊天，也没有向真实模型发送请求。

```bash
npm ci
npm run typecheck
npm test
npm run pack
npm run verify:reference
npm run verify:skins
npm run map:lab
npm run map:verify
mkdir -p .tmp/ui-baseline
git archive 7494ed6 ui | tar -x -C .tmp/ui-baseline
npm run verify:skin-performance
```

`ATLAS_CHROME_PATH` 指定可用浏览器；受限容器可使用 `ATLAS_BROWSER_SINGLE_PROCESS=1`。Windows 的默认 npm 测试命令可直接运行；性能基线解包命令需在 Git Bash 等带 tar 的终端中执行。浏览器、性能和临时日志位于 `.tmp/`，不进入正式安装目录。

协议、字段、资源规格、配额与程序接口见 [皮肤制作说明](atlas-skin-authoring.md)，安装见 [测试包说明](atlas-ui-skin-preview-install.md)。
