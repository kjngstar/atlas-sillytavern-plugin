# 同轮空间组装与地图分析导出验收（2026-10-11）

## 本次修改

- 删除室内图底部的尺寸辅助线和「宽度 … m」标注。比例尺、真实尺寸和导出坐标仍可用。
- 原流程将空间组装与观察、世界建设、后台任务共用四次传输预算，并在进入缺失布局的子图时自动补画。现在先冻结已登记的缺失/结构变化地图清单，再按每批两图处理，完成后一次发布候选。打开地图只读，不调用模型。
- 不重复生成结构未变化的已有布局。模型或连接失败仍记真实错误和未完成状态；不会把失败布局宣称为已完成。
- 修复新空图初始化为小数行数和旧尺寸别名不一致的问题，保留物理纵横比，使用等比例整数格幅面。
- 新增右侧工具栏「导出当前地图」：导出当前地图及子图的 JSON。选世界图可导出该视角内的世界层级。文件含地图关系、地点目录、原始约束、生成几何、真实坐标/尺度及画布投影；缺失布局明确标记。重复导航投影按地图 ID 去重。
- 导出窗口提供下载、复制及 JSON 查看入口。该格式用于分析，不是可直接导入的完整存档，不含连接设置、API 密钥或提示词文档。
- 修复观察与建设阶段重复登记远处同名房间：去重依据同一候选分支、父地点、类型及精确名称/别名，不受当前场所目录截断影响；内部先解析父声明，最终模型顺序与冻结短引用保持。不同父的同名房间不合并，已有歧义不擅自挑一个。此修复防止后续重复，不自动合并历史重复实体。
- 地点目录和分析导出包含父地点关系；主角视角不返回未知父地点的 ID。
