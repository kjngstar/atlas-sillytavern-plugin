# 父子地图导航与局部布局修复

基于 2026-10-28 的 main / v0.9.99（`78fb6e1`），叠加已完成的内容容量修复。

## 结果

- 导航只按现有 `parentMapId` 连接地图。移除 L0–L7 等级、等级阶梯与等级编号；面包屑和地图目录保留真实归属。
- 地点类型描述用途，`renderKind` 选择绘图模板。庭院保留 `other`，载具保留 `vehicle`，无需转换为地区或楼层来满足导航等级。
- 移除显示层把兄弟地图投影进子地图、剪裁子图并扩大子图幅面的逻辑。每张图使用自己的局部坐标与内容取景。
- 概览布局同时有 `near` 和 `sector` 时，方向相对参照地点计算。先解析参照地点，避免结果取决于地点 ID 的先后顺序。
- 有物理尺寸的空间按自身尺寸安排局部间隔；不因整张世界图很大而给附近两座空间留下巨大空隙。
- 增量更新预留旧轮廓和旧坐标的占位；保留已确认的位置、尺寸、几何与已有普通布局。

## 保留的空间语义

父子归属、尺寸权威账本、父图足迹尺寸、坐标单位换算、楼层入口、真实通行关系、作者确认与锁定继续有效。子图并不是父图某个示意轮廓的摄像机放大版，父图的远方兄弟不能撑大当前子图。

本次没有迁移或清空用户数据库。已保存的普通布局保持稳定；新的相对排位用于新增空间和重新提交的布局约束。截图本身不含原始坐标与存档，无法证明截图中每一处空白都来自同一个原因。
