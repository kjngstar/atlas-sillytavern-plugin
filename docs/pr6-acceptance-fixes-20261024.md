# PR6 验收问题修复

## 短视口的地图工具遮挡

1100×720、完整界面、事件栏展开时，地图视口只有 510×390。右侧工具栏下移到 68px 后，导出按钮落在右下小地图覆盖区；1280×720 下网格按钮也被盖住。提高工具栏层级会把遮挡转移给小地图。

在 `atlas-view-profiles.css` 中为导航列预留空间，将小地图的右边距设为 72px。工具栏、小地图和左下图例分别占用独立区域，不改变 Canvas、地图相机、收纳偏好或 SQL 数据。原始受保护样式未改。

扩展 `verify-map-widgets.mjs` 的回归覆盖：保留原有 1000px 高度的宽度矩阵，增加 1009/1100/1280/1440×720；将地图导出加入中心命中检查，并实际点击短视口的网格和导出按钮，检查图例、小地图、导航不重叠。

## 中文 Windows 的皮肤素材打包

`artwork-image.py` 用 `read_text(encoding="utf-8")` 读取 manifest，避免 Python 随 cp936/GBK 系统编码解码 UTF-8 JSON。

新增真实 Node → Python 打包回归，显式关闭 Python UTF-8 模式和 locale coercion，在 C locale 下打包晴空信笺及山河志。测试固定使用当前已安装 Pillow 的 Python 解释器，负面测试也使用同一解释器，避免因另一个 Python 缺少依赖而误判预期拒绝行为。

嵌套尺寸夹具的工具控制台曾出现无来源 URL 的 MutationObserver 异常。额外加入三层页面 error 捕获后均为空；直接打开同一打包工作台不复现此异常，仅有隔离宿主缺少 GENERATE_AFTER_DATA 事件的提示。原始日志与对照记录已保留，未将“控制台为空”列作本轮通过依据。

本轮使用隔离 SQL 宿主和 Codex 内置浏览器；没有覆盖用户的酒馆安装或聊天存档，也没有调用外部模型。扩展后的 Playwright 门禁已补充并通过语法检查，本轮浏览器通过项以上述内置浏览器实际复验为准。
