# 街巷与城镇略图验收（2026-10-31）

用户反馈：雨棚巷只有一条虚线；槐港镇把钟楼广场、石阶码头、集市画成铺满矩形画布的三块分区，缺乏地图空间感。

## 本次改动

- 缺少实测布局的街、路、巷使用有宽度的路面、双侧边缘和铺地。两出口的巷道合成一条连续路面，未确认的直线连接可以使用浅折线略图；确认路径不增加折线。没有连接记录时只画街道自身，不新增出口。
- 无已知内部建筑的街巷增加少量不带实体 ID 的街沿纹理，已有子地点轮廓时省略街沿纹理，避免覆盖真实建筑。出口仍使用现有地点图标，隐藏目的地不暴露。
- 城市模板生成的 Voronoi 分区不再直接当成广场、码头、集市的实际外墙。绘图投影保留原锚点，以留白的局部轮廓和按用途区分的纹理呈现；图上注明“地点轮廓为示意”。保留原多边形来源，不修改存档、实体坐标、路线或距离。
- 确认边界、已标定城市和包含已保存建筑的分区不改变轮廓；非模板轮廓不重画。城市道路投影保留 ID 和宽度，画成有路面的连接。
- 宿主验收发现原存档图标带 `placeId`，会误入单击查看详情分支。现在通过实际图标命中标记进入意图，单击进入子图；轮廓仍按原设置单击查看详情、双击进入。没有增加地图上的文字进入按钮。
