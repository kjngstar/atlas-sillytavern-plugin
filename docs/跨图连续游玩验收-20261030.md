## 已复现的问题

### 已有陈设搬动未落实

第7轮正文明确完成两条长凳贴左墙、备用缆绳移柜边及挂灯。候船棚前后约束及静态几何完全相同：`bench_1` 仍为 `(4.45,21.2)`，`bench_2` 仍为 `(4.45,22.7)`，均为 `3×1`；没有新增缆绳位置或挂灯约束。该轮主要新增埠头和渡船地点。

第8轮在原有候车厅复测，正文明确把长凳摆到北墙下；`waiting-bench` 仍为 `(0.7,4.45)`，`2.4×0.45`，没有移到北墙。长桌 `waiting-long-table` 仍为 `(0.45,5.2)`，`3×1.2`；原位置本来就靠西侧，因此不能仅凭长桌未移动判失败，北墙长凳是明确的复现依据。

这些比较包含 `layout.groups`、`bodies`、原式 `furniture` 和约束。候船棚的两条长凳、木柜、告示板确实已保存为组合陈设，不应因 `furniture` 数组为空误判陈设缺失。问题是后续搬动没有更新，具体失效在模型规划还是程序触发/应用环节，本轮只凭导出数据尚未定位。

### 主角称呼漂移后身份分裂

原用户角色林渡有稳定 ID `chr_b5faf136b77567ec79e992f6`。第5轮上游剧情改称用户为羽风灵，并把林渡另提及成牛车的主人；Atlas 新建 `chr_3c2d6dbb9fe06c8626ebdbd9`，以 protagonist 登记羽风灵，和岑叶一起到石桥，旧林渡仍留候车厅。

第6轮使用自然介绍姓名的对白再次明确林渡和岑叶，上游正文仍混写三人，地图没有恢复为原来的两人，而是同时保留林渡、羽风灵两个 protagonist。第8轮三人一起回到原工具间。上游正文身份混淆与地图缺少连续性保护共同暴露，不能只归咎于地图坐标计算。

### 新图尺度及桥梁表现

石桥新图只生成装饰河道，没有桥面或跨河通行几何，两人的图标位于河道两侧。该图未标定米数，图上间距不能直接当真实距离。

候船棚无正文精确尺寸，却估为 24×24 米；两条长凳、木柜和告示板集中在左下角，人物在中央，画面显得大而空。这里陈设存在，问题是估计幅面与陈设组织。

### 外门开合和遗留缺图

第4轮正文开启候车厅外门，第5轮明确关门压闩；地图约束与门数据没有相应状态变化，门相关变化只记录为事件。
