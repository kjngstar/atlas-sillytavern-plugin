## 改动

同一场所的子空间改为共享一片场地示意。程序将子空间周边、公共场地与登记出口的绘图范围做栅格并集，只描绘合并后的轮廓，去除内部拼接边；这不是实体墙、实测边界或新增道路。地区之间仍只沿实际登记连接组成示意范围，不自动给不相连的远处区域修路。

候船棚保留子图真实轮廓比例，并使用保存的棚门作为总览中的开口。埠头没有已保存轮廓时，保留同一场地内的开放区域和未探明边缘，不再生成十字形地块。载具使用符号，不画成固定地块。移除出口的虚拟终点圆点、粗管状连线和地点名胶囊，名称直接落在图中；小地图同步显示合并轮廓。

内置酒馆现有正文明确描述候船棚前的七级石阶通向埠头，可确认它们属于连续渡口活动场地。但持久场景缺少完整父图方位和通路几何，本次只改只读绘图，不将场地排版写成真实道路或距离。底部标识为“场地略图 · 范围与方位为示意”。

主要文件：`ui/atlas-survey-surface.mjs`、`ui/atlas-exploration-map.mjs`、`ui/atlas-reference/js/map.js`。没有修改 SQL 保存、回退或模型生成逻辑。
