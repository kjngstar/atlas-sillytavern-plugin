# 晴空信笺 1.0.1

Atlas 图片皮肤：晴蓝天空、奶白信纸、云朵窗框、纸飞机分隔纹，以及六类邮笺小标记。深蓝文字配浅色纸面，保留地图几何、文字标签与点击位置。

## 安装

1. 将 Atlas 更新到草稿 PR #5 的分支 `codex/ui-profiles-skin-runtime-rc2`，刷新酒馆页面。主插件版本号仍为 0.9.96。
2. 打开 Atlas → 预设与外观 → 外观 → 导入皮肤。
3. 选择本目录的 **Atlas-QingkongXinjian-1.0.1.zip**，无需解压；安装后会自动应用“晴空信笺”。

完整、地图专注和纯地图共用同一皮肤。可随时在“已安装皮肤”中切换或恢复默认；重新导入同一个 ID 会更新素材；1.0.0 用户更新扩展后重新导入 1.0.1 即可。皮肤保存于当前浏览器和酒馆地址，换浏览器或地址后重新导入 ZIP。

## 素材

| 文件 | 尺寸 | 用途 |
|---|---|---|
| sky-letter.webp | 1536×1024 | 晴空信纸窗口背景、地图装饰背景 |
| letter-paper.webp | 256×256 | 面板与地图纸面纹理 |
| cloud-frame.png | 256×256，透明 | 云朵窗框 |
| cloud-avatar.png | 128×128，透明 | 人物、详情与视图标识的专用圆形头像框 |
| letter-frame.png | 192×192，透明 | 面板、普通/激活按钮、输入与选中框 |
| airmail-divider.png | 512×112，透明 | 标题与底栏的纸飞机分隔纹 |
| character / place / item / message / event / exit.png | 各 96×96，透明 | 人物、地点、物品、消息、事件、出入口 |

12 张静态图片绑定 18 个资源位，同图复用只解码一次。安装包为 270,306 字节，素材总像素为 1,869,824，均低于运行时限制。ZIP 只包含 manifest 与 PNG/WebP 图片，不包含执行代码、字体或远程资源。

窗框使用 60 像素切片、18 像素显示边宽，装饰不挤占内容区；头像使用完整圆形素材。小图标采用主题细边框；文字按钮与面板的图片装饰按圆角裁切。控件保留焦点、激活、禁用和输入验证反馈，选中装饰不拦截点击。

## 构建与验收

在项目根目录运行：

```bash
node tools/build-qingkong-skin.mjs
node --test tests/atlas-qingkong-skin.test.mjs tests/atlas-shanhe-skin.test.mjs
npm run pack
node tools/verify-artwork-skin.mjs skins/qingkong-xinjian/Atlas-QingkongXinjian-1.0.1.zip
```

浏览器检查需要可用的 Playwright Chromium；也支持项目既有的 `ATLAS_CHROME_PATH` 或 `ATLAS_BROWSER_RUNTIME_MODULE` 覆盖。报告默认写入 `.tmp/artwork-skin/report.json`。

本包 3 项专项测试与山河志 13 项回归通过；专项检查涵盖完整资源位、像素预算、安装包与源素材逐字节一致，以及正文、次要文字、按钮、选中项、地图标签和状态文字的静态对比度。实际浏览器 32/32 通过：文件选择导入、本地保存、12 图解码、控件焦点与禁用反馈、三种配置在 360/720/1440 宽度的布局、地图标记点击、导出 ZIP、10 次往返切换、刷新恢复、移除回退与世界数据不变。新增导入与换肤前后几何、相机保持，以及旧包头像回退检查；桌面和窄屏画面已人工核对。

浏览器使用真实发布构建、Canvas、SQL/WASM 与 IndexedDB，酒馆宿主使用本地夹具；未将其记为用户真实酒馆与外部模型验收。测试环境缺少完整中文系统字体，随附字体子集外的字符在截图中可能缺字；中文依赖现有内置字体及系统回退，皮肤不另行加载字体。

## 制作记录

七张制作原图由内置 `image_gen` 生成：背景、云朵窗框、独立圆形头像框、控件框、纸面、分隔纹、六类标记图集。标记从透明 3×2 图集中逐格裁切；全部透明素材保留生成的 alpha。后处理仅做透明留边裁切、等比标记适配、缩放与静态编码，未用代码绘制替代图片。

完整提示词、生成文件名、运行素材尺寸、裁切范围和 SHA-256 见 [asset-build.json](asset-build.json)。运行素材均在 `assets/`，可直接复用或重新打包。
