# 山河志 · 青绿宣纸 1.1.0

Atlas 古风图片皮肤。主色为宣纸、青绿、朱砂与哑金；包含山水背景、透明玉金窗框、头像框、面板纹理和六类印章标点。1.1 新增薄金面板框、青玉按钮框、朱砂选中框与章节分隔纹，并接入按钮、输入框、浮层和选中卡片。

## 安装

1. 先更新到 PR #5 中包含山河志 1.1 控件资源的版本，或覆盖本次交付的扩展补丁。补丁适用于该 PR 的原生界面。
2. 打开 Atlas → 预设与外观 → 外观 → 导入皮肤，选择 `Atlas-ShanheZhi-1.1.0.zip`。
3. 在已安装皮肤中选择“山河志 · 青绿宣纸”。完整、地图专注、纯地图共享这套皮肤。

本版沿用 `user.shanhezhi`，重新导入会更新已安装的 1.0 素材。可随时切回星幕。图片由浏览器本地保存；换酒馆地址或浏览器时重新导入 ZIP。旧版扩展不认识新资源角色，需要先更新扩展，不应删除 manifest 字段强行导入。完整素材包不可直接作为皮肤 ZIP 导入。

共 13 张静态图片绑定 18 个资源位；复用图片只解码一次。地图继续使用现有几何与命中规则。山水画是屏幕底层装饰，不产生地点或可点击区域。

按钮提供普通、悬停/键盘焦点、按下和禁用反馈；激活项与主要操作沿用青玉底色。输入框保留占位文字、光标、键盘焦点与错误边框。选中框使用不接收点击的伪元素，保持原控件操作。状态提示区分信息、成功、警告和错误。

## 构建和验证

在项目根目录运行：

```bash
node tools/build-shanhe-skin.mjs
node --test tests/atlas-shanhe-skin.test.mjs tests/atlas-reference-map-render.test.mjs
```

构建器复用正式 ZIP 读写与图片校验。本次共 33 项自动检查通过，其中 12 项针对本包，21 项为既有地图渲染回归。覆盖导入导出、角色共享、切换清理、失败回滚、旧 v1 包兼容、切片单位及静态文字色对比度；另完成全部实际图片的像素解码、尺寸与透明通道检查。安装 ZIP 为 295,372 字节，低于 8 MiB 限制；总像素 1,923,072，低于 8,388,608 限制。

组件素材预览按 manifest 的实际图片、切片和边框宽度制作，展示普通/焦点/激活/禁用、输入验证和选中卡片，属于素材排版图。当前环境无法打开项目页面，浏览器与真实酒馆视觉验收尚未完成；自动检查不代表实机验收通过。`dev-preview/shanhe-skin.html` 是固定演示数据的原生界面夹具，可在正常项目预览服务中打开，不调用模型。
