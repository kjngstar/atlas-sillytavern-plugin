# 山河志 · 青绿宣纸 1.0.0

Atlas 古风图片皮肤。主色为宣纸、青绿、朱砂与哑金；包含山水背景、透明玉金窗框、头像框、面板纹理及六类印章标点。道路、水系、建筑、墙体、走廊、陈设和图签使用同一浅色笔触体系。

## 安装

1. 先更新到 PR #5 中包含“山河志”的版本，或覆盖本次交付的扩展补丁。补丁只适用于该 PR 的原生界面。
2. 打开 Atlas → 预设与外观 → 外观 → 导入皮肤，选择 `Atlas-ShanheZhi-1.0.0.zip`。
3. 在“已安装皮肤”中选择“山河志 · 青绿宣纸”。完整、地图专注、纯地图共享这套皮肤。

可随时切回星幕。图片由浏览器本地保存；换酒馆地址或浏览器时重新导入 ZIP。旧 PR #5 不认识新增图片角色，需要先更新扩展；不应删除 manifest 字段来强行导入。

## 内容

| 图片 | 尺寸 | 使用位置 |
|---|---|---|
| mountains.webp | 1536×1024 | 窗口山水背景、地图装饰背景 |
| xuan-paper.webp | 256×256 | 面板、状态提示、地图纹理 |
| jade-frame.png | 256×256，透明 | 九宫格窗框、头像框 |
| character / place / item / message / event / exit.png | 各 96×96，透明 | 人物、地点、物品、消息、事件、出入口；载具复用出入口角色 |

共 9 张静态图片绑定 12 个资源位。地形与实体仍由现有地图数据绘制；山水画是屏幕底层装饰，不产生地点或可点击区域。地图坐标、比例尺、物品尺寸、命中和知识过滤不随皮肤改变。
